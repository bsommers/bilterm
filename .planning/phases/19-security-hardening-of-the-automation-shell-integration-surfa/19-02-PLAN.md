<objective>
Harden the SSH argv builders against option injection (SEC-R04, D-05) and move the OpenSSH ControlPath and the session-save fallback into the per-user private dir (SEC-R03).

Purpose: a destination such as `-oProxyCommand=...` currently becomes an ssh option (local code execution); a `/tmp` ControlPath lets another local user hijack or squat the master connection socket.
Output: `validate_destination`, `Result`-returning builders that emit `--`, private `ssh-%C` ControlPath, validated `WindowManager` entry points, updated tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| config file / `:ssh` / `:remote` / RPC `remote.connect_*` -> ssh argv | user- or client-supplied destination string becomes an argv element |
| other local users -> ControlPath socket dir | shared /tmp lets others pre-create or connect to the master socket |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-10 | Elevation of Privilege | `build_ssh_args`, `build_ssh_tmux_cc_args` | high | mitigate | `validate_destination` rejects empty / leading '-' / whitespace / control chars; `--` emitted before destination; wm validates before split |
| T-19-11 | Spoofing / Info Disclosure | ControlPath socket | high | mitigate | ControlPath `<private_runtime_dir>/ssh-%C` (0700 dir, owner-verified); options omitted when no safe dir |
| T-19-01 | Tampering | session-save fallback | medium | mitigate | fallback via `secure_fs::private_runtime_dir`/`private_dir_in`, never a shared temp path |
| T-19-14 | Denial of Service | ControlPath length | low | mitigate | `%C` hash + 40-byte dir cap (dir + `/ssh-` + 40 + `.XXXXXXXXXXXXXXXX` temp suffix + NUL = 103 <= 104 macOS sun_path); options skipped otherwise |
</threat_model>
