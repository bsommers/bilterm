<objective>
Make the headless JSON-RPC daemon safe by default (SEC-R01): default 0600 Unix socket in the private dir, a pure listen-policy function enforcing loopback / `--allow-remote` + token rules (D-04), a per-connection `auth.login` bearer handshake (D-01), and a client that can authenticate.

Purpose: today `--headless --listen` binds any TCP address with no authentication, giving any network peer or local user full workspace control (pane.exec, file writes).
Output: generic-stream server, Unix listener, auth gate, listen policy, token-aware client — all in `src/api/mod.rs` with tests. CLI wiring is plan 19-06.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| network peer -> TCP listener | untrusted bytes; full control-plane authority if accepted |
| other local uid -> Unix socket | filesystem perms + peer credentials decide access |
| token file -> daemon / ctl | secret material on disk |
