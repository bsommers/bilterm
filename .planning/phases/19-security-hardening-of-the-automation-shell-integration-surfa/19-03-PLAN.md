<objective>
Move every Bilterm-chosen file under the per-user private dir with O_EXCL 0600 writes (SEC-R03): shell-integration rc files, the history export default and history fallback dir, and default `.cast` recordings.

Purpose: these paths are currently predictable names in the shared temp dir; a local attacker can pre-plant a symlink or a malicious rc file that the user's shell then sources (code execution), or read exported command history and recordings.
Output: call sites switched to `secure_fs`, tests updated/added.
</objective>
