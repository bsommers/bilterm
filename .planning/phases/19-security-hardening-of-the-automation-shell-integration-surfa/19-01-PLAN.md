## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| other local users -> shared temp dir | another uid can pre-create dirs, files, or symlinks at predictable paths |
| token file on disk -> daemon | file content becomes an authentication secret |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-01 | Tampering / EoP | `ensure_private_dir`, `private_dir_in` | high | mitigate | create with DirBuilderExt mode 0700; verify existing dir via symlink_metadata: is_dir, uid == geteuid, mode & 0o077 == 0; never chmod a foreign/loose dir |

| T-19-03 | Information Disclosure | `read_secret_file` | high | mitigate | O_NOFOLLOW open, fstat owner/mode check (mode & 0o077 == 0), min length 16, errors omit contents |
| T-19-04 | Spoofing | `constant_time_eq` | low | mitigate | XOR-fold compare without early exit |
