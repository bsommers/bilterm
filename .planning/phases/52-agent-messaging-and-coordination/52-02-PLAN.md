# Plan 52-02: Core Implementation (AgentMailRegistry, Mailbox, and Safety Guards)

## Objective
Implement `src/wm/agent_mail.rs`, integrate `AgentMailRegistry` into `WindowManager`, wire config toggles, and enforce all safety bounds.

## Tasks
1. Implement `src/wm/agent_mail.rs` (under 500 lines):
   - `AgentMessage`, `AgentDeliveryMode`, `AgentMailOp`.
   - `AgentMailRegistry`:
     - Naming map: stable name <-> `PaneId`.
     - Per-recipient inbox queues (`VecDeque<AgentMessage>`).
     - Loop guard counter on `reply_to` links (`MAX_HOPS = 8`).
     - Rate-limiting tracker (`MAX_MSGS_PER_WINDOW = 32`).
     - Message ID sequence generator.
     - Unread count queries (`unread_count(pane_id)`, `unread_count_by_name(name)`).
2. Wire `AgentMailRegistry` into `WindowManager`:
   - Initialize in `WindowManager::new_headless` / `new`.
   - Wire `[api] allow_agent_messaging` from `ApiConfig` in `src/config/dotted.rs`.
   - Implement `wm.agent_mail_apply(&AgentMailOp) -> Result<Option<String>, String>`.
   - Implement delivery modes:
     - `Mailbox`: queue in inbox and update unread count.
     - `Nudge`: queue in inbox AND check recipient pane is idle, not in alt screen, not in password prompt. Inject comment line to PTY. If busy/locked/alt-screen, keep safely in inbox and report suppression.
     - `File`: write message body via `secure_fs` (`agent-mail/<to>/msg-<id>.txt` with `0600` permissions), attach path to message, nudge if idle.
   - Clean up mailboxes when panes are closed (`wm.remove_pane`).
3. Unit tests within `src/wm/agent_mail.rs`.
