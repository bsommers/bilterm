Verified facts (commit 0915792, RESEARCH Pattern 6):
- `GuiImageTexture { id: u32, x_px, y_px, width_px, height_px: u32, pixel_width, pixel_height: u16, rgba_bytes: Vec<u8> }` (src/ui/renderer.rs:180-190). Pane canvases use ids `900_000 + pane id` (renderer.rs:778).
- `GuiFrameSurface::rasterize_rgba` and the X11 / Win32 / macOS presenters paint quads, then images (copy only where alpha > 0, NO blending, nearest-neighbour), then glyphs (renderer.rs:253-295, linux_x11.rs:443-461, win32_gdi.rs:462, macos_ct.rs:540). So: canvases must be opaque (filled with the window background), rendered 1:1 (`pixel_width == width_px`), labels stay as cell glyphs on top, and the cells under a texture must be cleared to spaces or braille/half-block glyphs would paint over it.
- Pane canvas texture push to copy: src/ui/renderer.rs:750-800. GUI detection: the code path is `GuiWorkspaceRenderer` itself (do not rely on `wm.gui_surface`).
- `PixelCanvasBuffer::{new, draw_line_aa, draw_bezier_aa, draw_circle_aa, draw_rect_aa, blend_pixel}` (src/ui/pixel_canvas.rs:134-260). Missing pieces (stroke width, glow, capsule) are added in `graph_raster.rs`.
- Headless GUI frame helper pattern: tests/phase46_display_modes.rs:150-159.

Dependency decision (D-10 requires a justification for any vector crate): tiny-skia is NOT added. The in-repo canvas already provides AA lines, Beziers and SDF circles, all three GUI backends already composite RGBA textures, and adding tiny-skia would add an MSRV/compile-time and cross-platform build surface for roughly 100 lines of missing stroke/glow code (RESEARCH Standard Stack + Package Legitimacy Audit). No package is installed in this plan.

Determinism: only `+ - * / sqrt` and polynomial Bezier evaluation in the static frame. Animation uses a phase `t = fract(tick * speed + k / n)` along each active edge; rotating icon segments use a const table of 12 unit vectors (no runtime trig). Tick source: `wm.drawer().tick_counter`.

Id ranges: graph texture `950_000`; navigator icons `960_000 + row_index` (row_index < 10_000).
