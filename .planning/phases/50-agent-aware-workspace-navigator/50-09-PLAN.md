Action-lowering rule (ARCH-R01, project CLAUDE.md): every visible effect of a key or mouse gesture lowers to `Action::Agents(..)` and runs through `wm.apply`; keys are rows of `AGENTS_WINDOW_BINDINGS` in src/input/keymap.rs. Pointer-gesture bookkeeping is not an operation: which drag is in progress (`AgentsDrag`) is stored with `wm.set_agents_drag(..)`, mirroring the existing `wm.set_wm_mouse_drag(..)` the modal drag uses; it changes nothing visible and no command could express it. The drag motion that follows lowers to `SetRect`, `Split` or `PinNode`.
