Action-lowering rule (ARCH-R01, project CLAUDE.md): every snoop and compose key and mouse gesture lowers to `Action::Agents(..)` and runs through `wm.apply`; keys are rows of `AGENTS_WINDOW_BINDINGS` in src/input/keymap.rs. The input module never edits snoop state itself. Text-field editing is the one place a key carries free text: in scope `KeywordEntry` a printable character without CONTROL/ALT lowers to `AgentsOp::KeywordEdit(KeywordEdit::Push(c))` (characters cannot be enumerated in a table); its executor edits the buffer in `SnoopState.keyword_entry`.

Scope resolution (most specific first; extends 50-08/50-09):
- keyword entry active -> `[KeywordEntry]`, then printable characters become `Push(c)`, then `[Window]` (so `m`, `*`, `[`, `]`, `<`, `>` type into the keyword instead of acting on the window).
- focus Compose -> `[Compose]`, then printable characters are swallowed with no Action and no state (Phase 50 keeps no compose text), then `[Window]`.
- focus Snoop -> `[Snoop, Window]`; focus Graph -> `[Grab (when on), Graph, Window]` (50-09).
