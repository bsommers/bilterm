Interfaces this plan creates (50-08..50-12 consume them; keep these names):
- `crate::wm::agents_window::{AgentsWindowState, GraphScene, SceneNode, SceneEdge, NodeKey, GraphSelection, GraphLayout, GraphDir}`. `NodeKey` is a stable string id: `user`, `api`, `mcp`, `pane:<id>`, `session:<name>`, `agent:<name>` (endpoint -> key mapping lives here and is reused by 50-10 and 50-12). `GraphScene { nodes: Vec<SceneNode { key, label, pos: (f32, f32) /* normalised 0..1 */, state: Option<AgentState>, selected }>, edges: Vec<SceneEdge { from, to, count, last_seq, active, selected }> }`. `GraphDir { Left, Right, Up, Down }`. `GraphDir` derives `Clone, Copy, Debug, PartialEq, Eq` and `NodeKey` derives `Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash`: both become payloads of `crate::action::Action` (which derives `Eq`) in 50-08/50-09.

Layout (D-08 Claude's discretion, recorded): one deterministic Fruchterman-Reingold layout shared by TUI and GUI. Nodes sorted by `NodeKey`; a new node starts next to an already-placed neighbour (offset from an FNV-1a hash of its key) or at a hash-derived point in [0.1, 0.9]^2; 60 iterations on a cold start, 20 iterations with initial temperature 0.05 on a warm start, pinned nodes never move; positions clamped to [0.05, 0.95]; node cap 64 (live panes always kept; oldest non-pane endpoints dropped first). Default window rect: centred, 80% x 70% of the workspace, minimum 40 x 12; nothing renders below a 30 x 10 workspace.

Right-hand pane in this plan: the newest bus events, one line each (`#<seq> <from> → <to> <kind>: <preview>`), newest at the bottom, follow mode. 50-10 turns it into the full snoop view.
