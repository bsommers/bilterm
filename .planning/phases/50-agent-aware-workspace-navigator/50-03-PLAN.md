Implement `classify` with this first-match table (thresholds are the recorded A2 assumption):
1. Blocked: `echo_locked` (password / canvas password prompt) or a profile `blocked` pattern in the tail text.
2. Errored: process exited with non-zero code, or an unseen finished command with non-zero exit code.
3. Done: process exited with code 0, or an unseen finished command with exit code 0.
