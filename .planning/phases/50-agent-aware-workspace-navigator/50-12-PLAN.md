Interfaces this plan creates:
- `crate::wm::drawer::CommsIndicator { Pair { partner_label: String, partner_key: NodeKey }, FanOut { count: usize } }` plus `NavigatorRowMeta.comms: Option<CommsIndicator>` and `NavigatorRowMeta.comms_active: bool`.
- `crate::wm::drawer::navigator::NavigatorDrawerState { pub comms_focus: Option<usize> }` (`#[derive(Clone, Debug, Default)]`, defined in src/wm/drawer/navigator.rs) and one field `pub navigator: navigator::NavigatorDrawerState` on `WorkspaceDrawer`. `comms_focus == Some(row)` means the comms glyph of row `row` has keyboard focus; it counts only while `drawer().selected_index == row`, so moving the selection clears it without editing the classic selection functions.
- drawer.rs budget (from 50-02): `WorkspaceDrawer` derives `Default`, so the single field line is the only src/wm/drawer.rs edit in this plan; all comms logic lives in src/wm/drawer/navigator.rs, src/wm/drawer/nav.rs and src/input/drawer_navigator.rs.
- `DrawerNavOp::OpenComms` (`:drawer comms`) and `DrawerNavOp::CommsFocus(bool)` (`:drawer comms-focus on|off`; sets or clears `drawer.navigator.comms_focus` for the selected row).
- `DrawerKeyScope::NavigatorComms` (active while `navigator_comms_focused()`; scopes `[NavigatorComms, Navigator]`). Rows: `Navigator` Right -> `CommsFocus(true)` (claim guard above), `Navigator` `o` -> `OpenComms`; `NavigatorComms` Enter -> `OpenComms`, Left and Esc -> `CommsFocus(false)`.
- `crate::ui::drawer::navigator::navigator_comms_cells(wm, workspace_area) -> Vec<NavigatorCommsCell { x, y, width, row_index }>`.

Glyphs (Claude's discretion; single-width BMP only): pair `⇄` alternating with `⇆` while active, ASCII `<>` / `><`; fan-out `⋔` + count (accent/bold pulse while active), ASCII `>>` + count. Partner label: `sanitize_display(label, 6)`. Window: partners within the last 60 s; active = last event within 1.5 s (tracker's last update instant). Layout: the comms indicator is right-aligned in pane rows; when the row is too narrow the title truncates first, then the partner label, never the glyph.
