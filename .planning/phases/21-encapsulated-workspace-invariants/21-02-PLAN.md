       - Define `#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord)] pub enum Focus { Quick, Pane(PaneId) }`.
       - Remove `pub` and `pub(super)` from all fields of `WindowManager`, and replace `help_visible`, `help_scroll`, `inspector_visible`, `inspector_scroll`, `menubar_open_category`, `menubar_selected_item`, `palette_visible`, `palette_query`, `palette_selected` with `modal: Modal`.
       - Implement `pub fn focus(&self) -> Focus` returning `Focus::Quick` when `self.quick_terminal.visible` and `Focus::Pane(self.active_pane_id())` otherwise.
       - Update `pub fn active_pane_id(&self) -> PaneId` to return `self.z_stack.top().unwrap_or(1)` (never returning `0`).
       - Update `pub fn hit_test_pane(&self, col: u16, row: u16, area: Rect) -> Option<(Focus, Rect, Rect)>` to return `Focus::Quick` for the quick terminal overlay and `Focus::Pane(id)` for workspace panes.
       - Add `pub fn pane_by_focus(&self, focus: Focus) -> Option<&CompositePane>` and `pub fn pane_by_focus_mut(&mut self, focus: Focus) -> Option<&mut CompositePane>`.
       - Implement `pub fn remove_pane(&mut self, target_id: PaneId) -> bool`:
         - If `self.panes.len() <= 1`, return `false`.
         - If `self.split_tree.remove_leaf(target_id)` is `true`, remove `target_id` from `self.panes` and `self.z_stack`, clear `self.zoomed_pane` if `Some(target_id)`, call `self.fleet.remove_pane_references(target_id)`, call `self.rebalance_scrollback(Instant::now())`, and return `true`.
       - Refactor `close_focused_pane(&mut self) -> bool` to hide `quick_terminal` if visible, otherwise call `self.z_stack.top().is_some_and(|id| self.remove_pane(id))`.
       - Add `pub fn poll_all_ptys(&mut self)` (polling all panes, reaping exited panes via `self.remove_pane(id)`, polling `quick_terminal`, and calling `self.maybe_rebalance_scrollback(Instant::now())`), `pub fn all_panes_exited(&self) -> bool`, `pub fn drain_outbound_osc52(&mut self) -> Vec<String>`, and `pub fn broadcast_command(&mut self, cmd: &str) -> Result<usize>`.
       - Add accessors/mutators on `WindowManager` for `pane_count`, `pane`, `pane_mut`, `panes`, `panes_mut`, `layout_mode`, `set_layout_mode`, `split_tree`, `z_stack`, `zoomed_pane`, `quick_terminal`, `quick_terminal_mut`, `is_quick_terminal_visible`, `config`, `config_mut`, `modal`, `modal_mut`, `close_modal`, `is_help_visible`, `help_scroll`, `is_inspector_visible`, `inspector_scroll`, `set_inspector_visible`, `is_palette_visible`, `palette_state`, `menubar_open_category`, `menubar_state`, `set_menubar_open_category`, `is_broadcast_input`, `is_leader_pending`, `set_leader_pending`, `fleet`, `fleet_mut`, `scrollback_mut`.
    2. In `src/remote/mod.rs` and `src/wm/session.rs`:
       - Add `FleetRegistry::remove_pane_references(&mut self, pane_id: PaneId)` to clean up `SshPane` and `SshTmux` entries referencing a removed pane.
       - Add `WindowManager::disconnect_fleet_node(&mut self, name: &str) -> bool` in `src/wm/session.rs` that removes `name` from `self.fleet.nodes` and calls `self.remove_pane(pid)` for any associated `SshPane` or `SshTmux` pane(s).
    3. In `src/vt/scrollback.rs` and `src/wm/session.rs`:
       - Add `quick_seen: bool` and `pub fn mark_quick_seen(&mut self) -> bool` to `ScrollbackGovernor` so `WindowManager::rebalance_scrollback` never inserts `0` into `seen: BTreeSet<PaneId>`.
