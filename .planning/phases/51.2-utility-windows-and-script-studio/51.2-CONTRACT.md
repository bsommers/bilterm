## 1. Architectural Decisions

- **D-01 First-Class Utility Windows**: Each utility window (`Fonts`, `CommandPalette`, `ScriptStudio`) is a distinct, first-class floating / pinnable / dockable component maintained within `WindowManager`. They do not block terminal PTY output or lock out other panes unless explicitly focused.
- **D-02 Unified Action Lowering (`ARCH-R01`)**: All user interactions (keyboard chords, in-window keys, mouse clicks/drags, colon commands, menu items, JSON-RPC, and MCP tools) lower to canonical `Action` variants:
  - `Action::FontsWindow(FontsWindowOp)`
  - `Action::CommandWindow(CommandWindowOp)`
  - `Action::ScriptStudio(ScriptStudioOp)`
- **D-03 Mutual Keyboard Focus & Modality Exclusion**: At most one utility window captures active keyboard input at any time. Clicking inside a window or issuing an `:open` command focuses it; pressing `Esc` or clicking outside blurs or dismisses it according to its pin state.
- **D-04 Pinning Semantics (`[•]` Pin Chip / `*` / `Alt+P`)**:
  - **Unpinned (default for one-shot launches)**: Pressing `Enter` commits the selection / command and immediately dismisses the window; pressing `Esc` dismisses the window.
  - **Pinned (`[•]` active)**: Stays open persistently. For `FONTS`, this enables live real-time A/B visual comparison while cycling fonts. For `COMMAND PALETTE`, this establishes a persistent interactive workbench capturing repeated executions and outputs in a scrollable history buffer. For `SCRIPT STUDIO`, the window remains open while stepping or inspecting output.
- **D-05 Docking Integration (`panel_dock.rs`)**:
  Each utility window supports `[□]` Dock / `d` toggle, docking cleanly into the tiling strip beside the terminal panes via `panel_dock.rs` (`DockPanel::Fonts`, `DockPanel::Command`, `DockPanel::ScriptStudio`), avoiding overlapping floating occlusions when desired.
- **D-06 Secure File Persistence (`SEC-R01..04`)**:
  `SCRIPT STUDIO` persists scripts exclusively under `~/.config/bilterm/scripts/<name>.bt` using `src/util/secure_fs.rs` (`ensure_private_dir` `0700`, `write_private_file_atomic` `0600`, and `validate_safe_name` rejecting path traversal `..`, `/`, `\`, and NUL bytes).
- **D-07 Action Recording**:
  When `SCRIPT STUDIO` recording is active (`[● Rec]` / `Ctrl+R`), executed `Action` variants and submitted colon commands are intercepted and appended as readable `.bt` script lines into the studio editor buffer.

## 2. Window 1 (`WIN-01`): `FONTS` Window

### 2.1 File Map
- State & WM Methods: `src/wm/fonts_window.rs`

- Test Suite: `tests/phase51_2_fonts_window.rs`

### 2.2 Operations & Colon Grammar (`FontsWindowOp`)
```rust
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum FontsWindowOp {
    Open,
    Close,
    Toggle,
    Dismiss,
    Blur,
    SelectUp,
    SelectDown,
    SelectFirst,
    SelectLast,
    PageUp,
    PageDown,
    SelectPreset(usize),
    ApplyActive,
    ApplyAll,
    ToggleApplyAll,
    Pin(Option<bool>),
    Dock(Option<bool>),
    PtStep(i16),
    ScaleStep(i16),
    Rescan(Option<String>),
    Move { dx: i16, dy: i16 },
    Resize { dw: i16, dh: i16 },
    SetRect { x: u16, y: u16, w: u16, h: u16 },
    Scroll(i16),
}
```

Colon syntax:
- `:fonts [open|close|toggle|dismiss|blur]`
- `:fonts pin [on|off|toggle]`
- `:fonts dock [on|off|toggle]`
- `:fonts apply [all|pane]`
- `:fonts pt <+n|-n|val>`
- `:fonts scale <+n|-n|val>`
- `:fonts rescan [dir]`
- Compatibility aliases: `:font list`, `:font presets`, `:font scan [dir]` open or focus the fonts window.

### 2.3 Keybindings & Controls
- **Global / Menubar**: `View -> Fonts Window` (`ViewMenu::FontsWindow`), leader `F` (`Toggle`).
- **In-Window Navigation**:
  - `Up` / `k`: `SelectUp`
  - `Down` / `j`: `SelectDown`
  - `PageUp` / `PageDown`: `PageUp` / `PageDown`
  - `Home` / `End`: `SelectFirst` / `SelectLast`
  - `Enter`: `ApplyActive` (dismisses if unpinned; updates active pane font in real time)
  - `a`: `ToggleApplyAll` (toggle applying font change across all panes)
  - `+` / `=`: `PtStep(1)`
  - `-`: `PtStep(-1)`
  - `]` / `[`: `ScaleStep(10)` / `ScaleStep(-10)`
  - `s`: `Rescan(None)` (rescans user font directories)
  - `*`: `Pin(None)` toggle
  - `d`: `Dock(None)` toggle
  - `Esc`: `Dismiss` (closes if unpinned, blurs if pinned)
- **Mouse / Chrome**:
  - Title bar: `[•]` Pin chip, `[□]` Dock chip, `[×]` Close button.
  - Drag title bar to move (`Move` / `SetRect`); drag edges to resize (`Resize`).
  - Single click list item: select & preview. Double click: apply & dismiss.

### 3.3 Pin Promotion & Workbench Mode
- Triggering `Ctrl+P` opens the standard one-shot command palette (`Modal::Palette`).
- Pressing `Alt+P`, `*`, or clicking `[•]` Pin promotes `Modal::Palette` to the first-class `CommandWindowState` with `pinned = true`.
- **Workbench Layout**:
  - Top: Search query input with fuzzy filtered candidate list.
  - Middle: Action descriptions and parameter hints.
  - Bottom: Scrollable `OUTPUT / HISTORY` pane recording timestamp, executed command/action, return code, and status message.
- Pressing `Enter` in pinned mode executes the command against `WindowManager`, appends execution telemetry to the history log, and keeps the window open with query ready for subsequent commands.

Colon syntax:

- `:studio [verb]` (alias for `:script`)

- `:script reset` (resets program counter to 0)
- `:script record [on|off|toggle]`
- `:script save [filename]`
- `:script load [filename]`
- `:script edit` (toggles editor typing mode)

### 4.3 Studio Capabilities
- **Script Buffer**: Multi-line editor holding `:colon` commands and comments (`#`).
- **Debugger Controls**:
  - `[▶ Run (F5)]`: Executes lines sequentially until completion or error.
  - `[⏭ Step (F10)]`: Single-steps one instruction. Moves program counter cursor `▶` to next line.
  - `[↺ Reset]`: Resets program counter `▶` to line 0 without clearing text.
  - `[● Rec (Ctrl+R)]`: Toggles live Bilterm action recorder. Appends executed commands to buffer.
  - `[✎ Edit (i)]`: Toggles text entry vs navigation mode.
  - `[💾 Save]` / `[📂 Load]`: Secure persistence via `~/.config/bilterm/scripts/*.bt`.
- **Live Output**: Embedded `RUN LOG` pane displaying line number, status, timestamp, and result output for each evaluated step.

## 5. Parity & Uniformity Contract (`UNI-R01`)

Every utility window operation is verified across:
1. **Key sequence**: Both host TUI and GUI modes.
2. **Mouse gestures**: Title bar chips (`[•]`, `[□]`, `[×]`), buttons, list clicks, wheel scrolls, edge drags.
3. **Colon commands**: Full round-trip parsing (`parse_colon_command`) and canonical formatting (`op.colon_form()`).
4. **Command Palette**: Searchable entries in `command_registry.rs`.
5. **Top Menu Bar**: Accessible via `View` and `Tools` menus.
6. **Automation API**: JSON-RPC and MCP exposure (`window.fonts`, `window.commands`, `window.script`).
