Key/mouse map (Claude's discretion; added to the 50-08 window key table so the uniqueness test covers it): `F6` cycles focus Graph -> Snoop -> Compose; in Snoop: `j`/`k`/Up/Down select, PageUp/PageDown scroll, Home oldest, End newest + follow on, `f` follow toggle, `/` keyword entry (typed chars build the keyword, Enter applies, Esc cancels entry only), `a` agent filter from the selected line's sender, `p` pair filter from the selected line, `c` clear filters, `y` copy. Mouse: click a line selects it and focuses Snoop, wheel scrolls (scrolling up turns follow off), clicking a filter chip's `×` removes that filter, clicking the `[copy]` header badge copies, clicking the compose line focuses Compose.
Message age is computed from the agent tracker's last update instant (deterministic under synthetic time).
