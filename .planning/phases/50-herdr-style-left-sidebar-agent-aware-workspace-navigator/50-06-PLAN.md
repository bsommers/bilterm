- The herdr key table lives in src/input/keymap.rs next to the existing tables: `pub enum DrawerKeyScope { Herdr }` (Clone, Copy, Debug, PartialEq, Eq; 50-12 adds `HerdrComms`), `pub const HERDR_DRAWER_BINDINGS: &[(DrawerKeyScope, KeyModifiers, KeyCode, Action)]`, and `pub fn herdr_drawer_action(scopes: &[DrawerKeyScope], key: KeyEvent) -> Option<Action>`: scopes are tried in the given order (most specific first); modifiers are compared with SHIFT removed for `KeyCode::Char` (like `default_pane_action`) and exactly for other codes, so Shift/Alt+Up/Down never match the plain arrow rows and keep their classic session-move meaning.
