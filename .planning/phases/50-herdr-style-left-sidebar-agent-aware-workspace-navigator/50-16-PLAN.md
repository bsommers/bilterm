Action-lowering rule (ARCH-R01, project CLAUDE.md): every key and mouse gesture in this plan lowers to `crate::action::Action` and runs through `wm.apply`. Key bindings are rows of `AGENTS_WINDOW_BINDINGS` in src/input/keymap.rs (scope `Window`, so they work in every window pane). The input module never mutates window state itself.
