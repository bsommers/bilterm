Interfaces this plan creates (Phase 51 contract, D-01 costly):
- `TrafficEndpoint { User, Api, Mcp, Pane(PaneId), Session(String), Agent(String) }`, `label()` -> `"you" | "api" | "mcp" | "#<id>" | "@<session>" | <agent name>`. `Mcp` means the Master Control Program console (`:mcp broadcast`), not the Model Context Protocol transport (that is `Api`). `Agent(String)` is reserved for Phase 51 named agents.
- `TrafficKind { Input, Exec, Keys, Broadcast, Message }`, `as_str()` -> `"input" | "exec" | "keys" | "broadcast" | "message"`. `Message` is reserved for Phase 51.
- `TrafficEvent { seq: u64, at: Instant, from, to, kind, preview: String, bytes: usize, redacted: bool }`.
- `TrafficBus` (cap `TRAFFIC_CAP = 512`, `PREVIEW_CAP = 160` chars): `record(...) -> u64`, `events_since(seq) -> impl Iterator<Item=&TrafficEvent>`, `latest_seq()`, `len()`, `dropped()`, `iter()`.
- `impl WindowManager`: `traffic(&self) -> &TrafficBus`, `record_traffic(from, to, kind, raw: &str, now) -> u64` (auto-redacts when `to` is a pane in a password / canvas-password prompt), `record_traffic_with(from, to, kind, raw, redact: bool, now) -> u64`, `partners_of(pane, window: Duration, now) -> Vec<TrafficPartner { endpoint, count, last }>`.

Recorded decisions (research defaults, not user-confirmed):
- Open Question 6: until Phase 51 the graph is star-shaped (external senders `you` / `api` / `mcp` fanning out to panes/sessions); tests inject synthetic events directly.
- Open Question 5 / Pitfall 10: Phase 50 does NOT publish bus events on `/events` or `events.poll`; the external event names (`agent.message` dotted vs existing snake_case `type` values) are chosen in Phase 51's 51-01 spec with user sign-off. This keeps the published API unchanged in Phase 50.
- Bus is in-memory only; nothing is persisted (no `secure_fs` use needed). Keystroke content is never logged via tracing.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| automation client -> pane (send_keys / exec) | keystrokes and commands may carry secrets |
| agent/program text -> bus preview | previews are later rendered in the snoop view |
| any producer -> bus memory | unbounded producers could exhaust memory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-50-11 | Information disclosure | `pane.send_keys` / broadcast previews | high | mitigate | redaction evaluated before dispatch for password / canvas-password prompts; preview `[redacted]`; content never written to tracing logs or disk; test `bus_password_target_redacted` and `bus_rpc_send_keys_records_keys_event` |
| T-50-12 | Denial of service | TrafficBus | medium | mitigate | 512-event ring with eviction counter; 160-char preview cap applied before storage |
| T-50-13 | Tampering | preview text | medium | mitigate | `sanitize_display` strips control and bidi characters at record time |
| T-50-14 | Repudiation | event origin | low | mitigate | every event records its transport origin (`User` / `Api` / `Mcp`) via `is_api_origin()` and the producer site |
| T-50-SC | Tampering | cargo dependencies | high | mitigate | no new crates; `git diff --exit-code Cargo.toml Cargo.lock` |
</threat_model>
