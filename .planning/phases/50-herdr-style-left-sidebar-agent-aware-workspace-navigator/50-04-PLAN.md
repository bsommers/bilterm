Glyph/colour choices (Claude's discretion per CONTEXT, research A8): Working = braille spinner frame `BRAILLE_SPINNER_FRAMES[tick % 10]` / ASCII `*`, colour `success`; Blocked `▲` / `!`, `warning`; Idle `○` / `-`, `text_muted`; Done `●` / `+`, `accent` (herdr's "finished in background" blue dot); Errored `✗` / `x`, `danger`. Colours come from `crate::ui::design::DesignTokens::from_palette(palette)`. Spinner frame uses `wm.drawer().tick_counter` (deterministic in tests; animation cadence is 50-06).

Leader keys: `!` is unused in `DEFAULT_LEADER_BINDINGS` (verified at planning: 0 occurrences of `Char('!')`, no duplicate keys in the table).

Attention order (Claude's discretion, recorded): pick the highest non-empty tier among Blocked > Errored > Done; within the tier cycle in `ordered_pane_ids()` order starting after the active pane; focusing a Done/Errored pane marks it seen (50-03 rule) so it leaves the tier.
