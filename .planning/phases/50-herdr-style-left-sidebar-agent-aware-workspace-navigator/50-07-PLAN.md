Interfaces this plan creates:
- `crate::wm::agents_window::{AgentsWindowState, GraphScene, SceneNode, SceneEdge, NodeKey, GraphSelection, GraphLayout}`. `NodeKey` is a stable string id: `user`, `api`, `mcp`, `pane:<id>`, `session:<name>`, `agent:<name>`. `GraphScene { nodes: Vec<SceneNode { key, label, pos: (f32, f32) /* normalised 0..1 */, state: Option<AgentState>, selected }>, edges: Vec<SceneEdge { from, to, count, last_seq, active, selected }> }`.
- `AgentsWindowState { active, pinned, focused, rect: Option<Rect>, maximized, splitter_pct: u16 /* default 55 */, selection: GraphSelection, layout: GraphLayout }` + `captures_input()`.
- `impl WindowManager { agents_window(), agents_window_mut(), open_agents_window(focus: Option<PaneId>), close_agents_window(), agents_graph_scene() -> GraphScene, agents_window_rect(workspace_area) -> Option<Rect> }`.
- `AgentsOp` gains `Zoom(Option<PaneId>)` and `Close`; `:agents zoom [pane-id]`, `:agents close`.
- `crate::ui::graph_raster::{draw_agent_graph(canvas, scene, colours, tick), render_graph_tui(scene, rect, buf, palette)}`; `crate::ui::agents_ui::render_agents_window(wm, workspace_area, cfg, palette, glyphs, buf)`.

Layout (D-08 Claude's discretion, recorded): one deterministic Fruchterman-Reingold layout shared by TUI and GUI. Nodes sorted by `NodeKey`; a new node starts next to an already-placed neighbour (offset from an FNV-1a hash of its key) or at a hash-derived point in [0.1, 0.9]^2; 60 iterations on a cold start, 20 iterations with initial temperature 0.05 on a warm start, pinned nodes (50-08 drag) never move; positions clamped to [0.05, 0.95]; node cap 64 (live panes always kept; oldest non-pane endpoints dropped first). Default window rect: centred, 80% x 70% of the workspace, minimum 40 x 12; nothing renders below a 30 x 10 workspace.

Right-hand pane in this plan: the newest bus events, one line each (`#<seq> <from> → <to> <kind>: <preview>`), newest at the bottom, follow mode. 50-09 turns it into the full snoop view.
