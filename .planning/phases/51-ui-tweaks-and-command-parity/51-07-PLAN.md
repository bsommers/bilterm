## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard / mouse events -> window manager | any key or click while a window is focused |
| input handler -> pane PTY | a focused window must not leak keys, and an unfocused one must not eat them |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-51-19 | Denial of Service | drag arithmetic overflow from extreme pointer coordinates | low | mitigate | rects are computed with saturating math and clamped by the `SetRect` executor; drag test uses coordinates at `u16::MAX` |
| T-51-SC | Tampering | cargo installs | high | mitigate | no new dependency; `git diff --exit-code HEAD -- Cargo.toml Cargo.lock` |
