<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| colon / RPC / MCP text -> parser | untrusted strings reach `parse_agents_list` (arguments up to RPC size limits) |
| process names and titles -> list rows | agent names come from running commands and terminal titles |
| `:agents demo stop` -> pane close | future capability reachable over RPC/MCP |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-51-01 | Tampering / DoS | parse_agents_list numeric arguments | medium | mitigate | checked `u16`/`i16` parsing, ranges enforced (scale 75..=200), wrong arity is an Err; garbage-input test proves no panic |
| T-51-02 | Information Disclosure / Spoofing | row names in the AGENTS window | medium | mitigate | rows built from `agent_statuses()` names only (identity token, never screen text or arguments) and passed through `sanitize_display` so control or bidi characters cannot spoof the list |
| T-51-03 | Elevation of Privilege | `:agents demo stop` over RPC/MCP | low | accept | this plan ships a no-op stub; D-01 allows the verb with no new gate, 51-03 restricts the real body to panes the demo spawned |
| T-51-SC | Tampering | cargo installs | high | mitigate | no new dependency in this phase; acceptance criterion `git diff --exit-code HEAD -- Cargo.toml Cargo.lock` |
</threat_model>
