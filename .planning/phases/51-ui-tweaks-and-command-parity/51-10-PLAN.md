<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| remote API client -> `agents.list` / `agents.demo` params | untrusted JSON from any transport (socket, TCP, loopback HTTP with bearer token, MCP) |
| params -> colon string -> parser | string assembly is the injection surface |
| `agents.demo stop` -> pane close | reachable by any authenticated API client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-51-25 | Tampering / Elevation of Privilege | command injection through args (a second colon command such as `:quit` or `:set` riding in a token) | high | mitigate | closed op set, per-token charset `[A-Za-z0-9+\-_.#%:]` with no leading colon, no whitespace/newline/`;`, length and count caps; `agents_list_rejects_bad_params` includes injection payloads; the config write gate still applies to anything that reaches `:set` through other methods |
| T-51-26 | Tampering | `agents.demo stop` closing user panes | high | mitigate | stop only closes demo-spawned panes (51-03, T-51-06); no new capability beyond what `wm.command ':agents demo stop'` already allowed |
| T-51-27 | Denial of Service | oversized params or repeated demo runs | low | mitigate | size caps on tokens, existing request-size limits of the transports, demo replace-on-rerun (51-03) bounds growth |
| T-51-28 | Information Disclosure | summaries leaking pane names or screen text | low | mitigate | `agents_list` / `demo` objects hold only flags, counts and pane ids; names stay in the existing `data` payload (Phase 50 contract) |
| T-51-SC | Tampering | cargo installs | high | mitigate | no new dependency; `git diff --exit-code HEAD -- Cargo.toml Cargo.lock` |
</threat_model>
