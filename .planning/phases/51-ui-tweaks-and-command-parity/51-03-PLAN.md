| ring events -> predicate | stop deletes events by predicate, so it must not match real traffic |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-51-06 | Elevation of Privilege / Tampering | stop closing a user's pane | high | mitigate | close only ids in `spawned` (pane ids absent before the run), skip missing ids, never close endpoints that pre-existed, state cleared on new-session and layout restore (51-02 hooks) against id reuse; tests stop_closes_spawned_panes, session_reset_clears_demo |
| T-51-07 | Tampering | event predicate deleting real messages | medium | mitigate | predicate requires kind Message AND `[demo] ` prefix AND both endpoints in the demo endpoint set; stop_removes_only_demo_events |
| T-51-08 | Information Disclosure | unredacted demo previews | low | accept | text is the fixed `DEMO_SCRIPT` constants, never user data; redaction would hide the prefix the predicate needs (D-01) |
| T-51-09 | Denial of Service | O(n) retain over a 512-entry ring | low | accept | bounded by `TRAFFIC_CAP`, runs once per explicit command |
