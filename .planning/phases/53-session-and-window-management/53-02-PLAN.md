<tasks>
1. Implement Window Migration Logic in `src/wm/window_manage.rs` (`SES-01`):
   - `WindowManager::move_window_to_session(&mut self, window_id: Option<PaneId>, target_session: &str, switch: bool) -> Result<()>`:
     - Check target session existence (in `SessionTree`, `layout_profiles_mem`, or on disk).
     - Guard against moving to the current active session.
     - Detach live `CompositePane` from source `panes`, `split_tree`, `z_stack`, and `zoomed_pane`.
     - Update focus and z-order in source session; ensure source session is not left orphaned without windows (spawn default shell if last pane removed).
     - Attach `CompositePane` to target session (in-memory if target is background session or active session).
     - Maintain PTY fd, child process, scrollback buffer, and running command untouched.
2. Implement Rename Operations (`SES-02`):
   - `WindowManager::rename_window(&mut self, window_id: Option<PaneId>, new_name: &str) -> Result<String>`:
     - Validate `new_name` via `validate_safe_name`.
     - Check duplicate name collision in current session; reject or disambiguate with `-2`, `-3` suffix.
     - Update title in `CompositePane` and pane chrome.
   - `WindowManager::rename_session(&mut self, old_name: Option<&str>, new_name: &str) -> Result<(String, String)>`:
     - Validate `new_name` via `validate_safe_name`.
     - Handle hierarchical path renames in `SessionTree`.
     - Update disk TOML files and `layout_profiles_mem` keys atomically.
3. Implement Multi-Selection and Bulk Actions (`SES-03`):
   - Add selection state to `WindowManager`: `selected_windows: BTreeSet<PaneId>`.
   - Implement `select_window(&mut self, target: WindowSelectTarget)`.
   - Implement `apply_bulk_op(&mut self, op: WindowBulkOp) -> Result<usize>`:
     - Pre-validate all selected windows (check exit guards, non-empty workspace invariants).
     - Atomic all-or-nothing execution: abort and rollback if any window fails.
     - Implement `BulkMove`, `BulkClose`, `BulkRenamePrefix`, `BulkTile`, `BulkPin`.
4. Implement Single-Step Undo Stack (`SES-04`):
   - Add `topology_undo: Option<WorkspaceTopologyUndo>` to `WindowManager`.
   - Capture snapshot before any mutating move, rename, or bulk action.
   - Implement `WindowManager::undo_topology(&mut self) -> Result<String>` restoring prior layout, names, order, and selection.
5. Session TOML and Daemon Persistence (`SES-04`):
   - Update `SavedWorkspaceSession` and `SavedPaneState` to serialize window names, custom order, and multi-selection.
   - Ensure older TOML files load cleanly without error via `#[serde(default)]`.
   - Sync session tree changes to `daemon_state.session_tree`.
6. Implement Core Test Suite `tests/phase53_window_manage.rs`:
   - Test live PTY process and scrollback preservation across session moves.
   - Test move to nested session (`parent/child`).
   - Test duplicate rename rejection and disambiguation.
   - Test multi-selection permutations (toggle, range, all, none, invert).
   - Test bulk operations and exit guard enforcement.
   - Test single-step undo restoration.
   - Test TOML serialization and deserialization round-trip.
</tasks>
