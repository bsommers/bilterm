<task id="58-01-01">
<title>Add `SttConfig` to `src/config.rs` and implement `src/stt/wav.rs` + `src/stt/mod.rs`</title>
<description>
1. In `src/config.rs`, define `SttConfig` (and wire `#[serde(default)] pub stt: SttConfig` into `Config`):
   - Fields: `enabled: bool` (`false`), `provider: String` (`"openai_compatible"`), `endpoint: String` (`"http://127.0.0.1:8080/v1/audio/transcriptions"`), `model: String` (`"whisper-1"`), `language: Option<String>` (`Some("en")`), `vocabulary_prompt: Option<String>`, `api_key_file: Option<PathBuf>`, `allow_remote_stt: bool` (`false`), `audio_backend: String` (`"auto"`), `max_recording_secs: u64` (`60`, clamped `1..=300`), `auto_stop_silence_ms: u64` (`1500`), `vad_threshold_db: f32` (`-38.0`), `auto_submit: bool` (`false`), `cli_command: Vec<String>`.
   - Implement `SttConfig::validate_endpoint(&self) -> Result<(), String>` verifying that the host in `endpoint` is loopback (`127.0.0.1`, `::1`, `localhost`, or `unix://`) whenever `!self.allow_remote_stt`.
   - Implement `SttConfig::load_api_key(&self) -> Result<Option<String>, String>` reading and trimming `api_key_file` after verifying `0600` permissions on Unix.
2. Create `src/stt/wav.rs`:
   - `pub const STT_SAMPLE_RATE: u32 = 16_000;`
   - `pub fn encode_wav_s16le_mono(samples: &[i16]) -> Vec<u8>` and `pub fn encode_pcm_bytes_to_wav(pcm_s16le: &[u8]) -> Vec<u8>` writing a standard 44-byte RIFF/WAVE header followed by the PCM payload.
   - `pub fn parse_wav_s16le_mono(wav_bytes: &[u8]) -> Result<Vec<i16>, String>` for validation and `voice.inject_wav` testing.
   - `pub fn compute_rms_dbfs(samples: &[i16]) -> f32` returning decibels relative to full scale (`-96.0..=0.0`).
   - `pub struct ScrubbedTempWav` RAII struct that writes a `0600` WAV file inside `secure_fs::ensure_private_dir(&runtime_dir.join("stt"))` and overwrites with zeros + unlinks in `Drop`.
3. Create `src/stt/mod.rs` exporting `wav`, `audio`, `provider`, `worker`, and shared types (`SttBackendKind`, `SttUiStatus`, `SttEvent`, `TranscriptionRequest`, `TranscriptionResponse`), and register `pub mod stt;` in `src/lib.rs`.
</description>
</task>

<task id="58-01-02">
<title>Implement cross-platform audio capture (`src/stt/audio.rs`) and local AI STT providers (`src/stt/provider.rs`)</title>
<description>
1. Create `src/stt/audio.rs`:
   - Define `AudioRecorderKind` (`PwRecord`, `PaRecord`, `ARecord`, `SoxRec`, `Ffmpeg`, `Mock`) and `probe_available_recorder(preferred: &str) -> Result<AudioRecorderKind, String>`.
   - Build exact subprocess command arguments for 16 kHz, 16-bit signed LE, 1-channel raw PCM to `stdout` (`-`).
   - Implement `SubprocessAudioCapture` and `MockAudioCapture` (generating configurable speech-level sine/PCM frames followed by silence frames for VAD testing), enforcing `max_recording_secs` byte limits (`16000 * 2 * max_secs`).
2. Create `src/stt/provider.rs`:
   - Define async `SttProvider` trait (`async fn transcribe(&self, req: &TranscriptionRequest) -> Result<TranscriptionResponse, String>`).
   - Implement `OpenAiCompatSttProvider`:
     - Parses `http://<host>:<port>/<path>` (after `SttConfig::validate_endpoint`).
     - Connects via `tokio::net::TcpStream` with connect/read timeouts, formats a RFC 7578 `multipart/form-data` request with `file` (`audio.wav`, `audio/wav`), `model`, optional `language`, optional `prompt`, and `response_format="json"`.
     - Attaches `Authorization: Bearer <token>` if `api_key_file` is configured.
     - Bounds response read to `64 KiB`, handles chunked or content-length bodies, and extracts `"text"` from the JSON payload (or plain text if `response_format="text"`).
   - Implement `OllamaSttProvider`:
     - Sends `POST /api/generate` or `/api/chat` over `tokio::net::TcpStream` with base64-encoded WAV data and prompt, parsing the JSON `"response"` / `"message.content"` field.
   - Implement `LocalCliSttProvider`:
     - Materializes a `ScrubbedTempWav`, substitutes `{wav_path}` in `cli_command`, runs `tokio::process::Command` with timeout, and collects `stdout` transcript.
   - Implement `MockSttProvider` returning deterministic transcripts for unit/integration tests.
</description>
</task>

<task id="58-01-03">
<title>Implement `SttWorker` (`src/stt/worker.rs`) and Wave 1 test suite (`tests/phase58_stt_module_and_providers.rs`)</title>
<description>
1. Create `src/stt/worker.rs`:
   - Define `SttCommand` (`Start { pane_id: Option<usize> }`, `Stop`, `Cancel`, `InjectWav { pane_id: Option<usize>, wav_bytes: Vec<u8> }`, `SetProvider(SttBackendKind)`, `Shutdown`) and `SttHandle` holding `mpsc::Sender<SttCommand>`.
   - Implement `SttWorker::spawn(config: SttConfig, event_tx: mpsc::UnboundedSender<SttEvent>) -> SttHandle`:
     - Streams 100 ms PCM chunks during active recording, emits `SttEvent::Telemetry { recording, transcribing, rms_db, elapsed_ms, error }`.
     - Implements VAD silence auto-stop when `auto_stop_silence_ms > 0` after initial speech activation (`rms_db >= vad_threshold_db`).
     - On `Stop` or VAD auto-stop, encodes the WAV buffer and invokes the active `SttProvider`, emitting `SttEvent::Transcript { pane_id, text, is_final: true }`.
2. Create `tests/phase58_stt_module_and_providers.rs`:
   - Test `SttConfig` defaults and `validate_endpoint` rejecting remote URLs (`http://api.openai.com/...`) when `allow_remote_stt == false` and allowing `127.0.0.1` / `localhost`.
   - Test `encode_wav_s16le_mono` / `parse_wav_s16le_mono` round-trip, `compute_rms_dbfs`, and `ScrubbedTempWav` `0600` creation + automatic removal on drop.
   - Test `OpenAiCompatSttProvider` against an in-process `tokio::net::TcpListener` mock server verifying valid `multipart/form-data` headers, WAV payload, `Authorization` header from `0600` `api_key_file`, and JSON `{"text": "cargo test -q"}` extraction.
   - Test `OllamaSttProvider` against a mock `TcpListener` Ollama server.
   - Test `LocalCliSttProvider` with `/bin/sh -c "echo 'git status -sb'"` verifying `{wav_path}` substitution and temp file cleanup.
   - Test `SttWorker` end-to-end with `MockAudioCapture` + VAD auto-stop emitting telemetry and final transcript events.
3. Run `scripts/verify.sh --only clippy unit t:phase58_stt_module_and_providers` to confirm green compilation and tests.
