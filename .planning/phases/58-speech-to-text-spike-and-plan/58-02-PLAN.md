<task id="58-02-01">
<title>Wire `Action::Voice(VoiceOp)`, `:voice` colon commands, keybindings, and `WindowManager` state</title>
<description>
1. In `src/action.rs`:
   - Define `VoiceOp` (`Toggle`, `Start { pane_id: Option<usize> }`, `Stop`, `Cancel`, `Status`, `SetProvider { provider: SttBackendKind }`, `InjectWav { pane_id: Option<usize>, wav_base64_or_hex: Vec<u8> }`, `ApplyTranscript { pane_id: Option<usize>, text: String, is_final: bool }`, `UpdateTelemetry { recording: bool, transcribing: bool, rms_db: i32, elapsed_ms: u64, error: Option<String> }`) and add `Action::Voice(VoiceOp)`.
   - Register `Action::Voice(VoiceOp::Toggle)` in `src/action.rs::tests::every_action_is_reachable_from_keymap_colon_or_rpc`.
2. In `src/colon_command/parse.rs` and `src/colon_command/complete.rs`:
   - Parse `:voice` (and alias `:stt`) subcommands:
     - `:voice` or `:voice toggle` -> `Action::Voice(VoiceOp::Toggle)`
     - `:voice start [pane_id]` -> `Action::Voice(VoiceOp::Start { pane_id })`
     - `:voice stop` -> `Action::Voice(VoiceOp::Stop)`
     - `:voice cancel` -> `Action::Voice(VoiceOp::Cancel)`
     - `:voice status` -> `Action::Voice(VoiceOp::Status)`
     - `:voice provider <openai|ollama|cli|mock>` -> `Action::Voice(VoiceOp::SetProvider { provider })`
   - Add `<Tab>` completion for `:voice` and its subcommands in `src/colon_command/complete.rs`.
   - Register `:voice` in `src/command_registry.rs` so it appears in the Command Palette (`Ctrl+P`) and `:help`.
3. In `src/input/keymap.rs`:
   - Bind `Ctrl+B v` in `DEFAULT_LEADER_BINDINGS` and `Alt+v` in `DEFAULT_GLOBAL_BINDINGS` to `Action::Voice(VoiceOp::Toggle)`.
4. In `src/pane/mod.rs` and `src/wm/mod.rs`:
   - Add `pub fn insert_dictated_text(&mut self, text: &str)` on `CompositePane` that focuses `Focus::FloatingPrompt` (when not in alternate screen without `force_command_prompt`), inserts a separating space if needed, and appends the dictated text into the `FloatingCommandPrompt`.
   - Add private `stt_status: SttUiStatus` and `stt_handle: Option<SttHandle>` fields to `WindowManager` with `pub fn stt_status(&self) -> &SttUiStatus` and `pub fn drain_stt_events(&mut self)`.
   - Handle all `Action::Voice(op)` variants in `src/colon_command/execute.rs`.
</description>
</task>
