<objective>
Fix copying from panes running nested TUIs (herdr, Claude Code) that enable alt-screen and mouse tracking (`COPY-01`). Root causes reproduced headlessly in 62-RESEARCH.md: Shift is not a selection override and SGR encoding drops modifier bits (D1); selections are not copied on release (D2); inbound OSC 52 is lost when split across the 8192-byte PTY reads (D3); a finished mouse selection leaves copy mode active and swallows every key (D4); no discoverable alt-screen entry or mouse-capture cue (D5).

Out of scope (Phase 62-02): scrollback-absolute selection, word/search motions, vi/emacs profiles, multi-click, hint line. Out of scope (Phase 63): global hotkey/profile changes and the herdr `Ctrl+B` prefix collision; reference only.
</objective>
