<task type="auto">
  <name>Task 2: Implement Whole-Workspace Asciicast v2 (.cast) Compositor Frame Recorder (REC-02)</name>
  <files>src/vt/recording.rs, src/wm/mod.rs, src/colon_command/execute.rs, src/app.rs, src/ui/renderer.rs</files>
  <action>
    1. In `src/vt/recording.rs`, implement `pub struct WorkspaceRecorder`:
       - Stores `started_at: Instant`, `path: PathBuf`, `private: bool`, `width: u16`, `height: u16`, `prev_cells: Vec<(String, ratatui::style::Style)>`, and `events: Vec<(f64, String)>`.
       - `pub fn capture_buffer(&mut self, buf: &ratatui::buffer::Buffer)`: diffs `buf` against `prev_cells` (or emits a full frame on first capture / resize), emitting compact ANSI cursor moves (`\x1b[{row};{col}H`), SGR foreground/background/modifier sequences, and cell symbols, and appends `(elapsed_secs, ansi_chunk)` when non-empty.
       - `pub fn stop(self) -> std::io::Result<PathBuf>`: writes the standard asciinema v2 header (`{"version":2,"width":W,"height":H,"timestamp":1792550000}\n`) followed by `[elapsed,"o","escaped_ansi"]\n` lines using `crate::secure_fs::create_private_file` when `private == true` (`SEC-R03`).
    2. Add `workspace_recorder: Option<WorkspaceRecorder>` to `WindowManager` with `start_workspace_recording(path, private)`, `stop_workspace_recording()`, `is_workspace_recording()`, and `record_workspace_frame(buf: &Buffer)`.
    3. Call `wm.record_workspace_frame(buf)` after rendering `WorkspaceWidget` in `App::run` and `RatatuiWorkspaceRenderer::render_workspace` (or inside `WorkspaceWidget::render`).
    4. Wire `Action::RecordStart { path, workspace }` and `Action::RecordStop` in `src/colon_command/execute.rs` so `:record start [path]` starts whole-workspace recording (and also records on the active pane's `VtParser` so `pane.vt().is_recording()` stays true for backward compatibility with existing tests), while `:record stop` stops and flushes the recording.
