<task id="60-01-03" name="RFC 6455 WebSocket Upgrade & Protocol Bridge">
Implement the WebSocket server and `@agent-manager/protocol` v1 dispatcher in `src/api/ws.rs`.
- In `src/api/ws.rs`:
  - Implement self-contained pure Rust SHA-1 digest (~45 lines, RFC 3174).
  - Implement `handle_upgrade(req, stream)`:
    - Validate `Upgrade: websocket` and `Sec-WebSocket-Key`.
    - Compute `Sec-WebSocket-Accept` using SHA-1 and `crate::vt::codec::base64_encode`.
    - Transmit HTTP `101 Switching Protocols`.
  - Implement WebSocket frame parser and writer:
    - Parse opcode (text `0x1`, close `0x8`, ping `0x9`, pong `0xA`).
    - Unmask client-to-server payload using 4-byte XOR mask.
    - Format unmasked server-to-client text frames with proper length encoding (7-bit, 16-bit, 64-bit).
  - Implement per-pane monotonic sequencing:
    - `seq: u64` initialized to 1 for each pane.
    - Ring buffer retaining up to 256 KiB of output chunks.
    - Handle `resumeFrom` replay and `agent:gap` emission.
  - Implement protocol message router:
    - `hello` -> validate `contract: 1`, record client info, reply with `hello_ack` and `agent:init_list`.
    - `ping` -> reply with `pong`.
    - `agent:input` -> write data to pane's PTY.
    - `agent:resize` -> trigger pane resize action.
    - `agent:create` -> spawn new pane via `Action::Split` or `Action::NewWindow`.
    - `agent:kill` -> close pane via `Action::ClosePane`.
    - `agent:broadcast` -> send keys to all specified target panes.
    - `agent:history` -> fetch past chunks from ring buffer.
- In `src/api/http.rs`:
  - Route incoming requests with `Upgrade: websocket` at path `/ws` to `src/api/ws.rs::handle_upgrade`.
</task>
