<task id="60-02-01" name="Multi-Client View State Isolation (src/api/client_view.rs)">
Build the client view state registry isolating web client viewport and focus from local TUI state (`WEB-FE-03`, `ARCH-R02`).
- In `src/api/client_view.rs`:
  - Define `ClientViewState`:
    - `client_id: String` (connection ID or UUID).
    - `viewport_cols: u16`, `viewport_rows: u16`.
    - `focused_pane_id: Option<PaneId>`.
    - `scroll_offsets: HashMap<PaneId, usize>`.
    - `active_modal: Option<String>`.
    - `last_seen_epoch_ms: u64`.
  - Define `ClientViewRegistry`:
    - Wrapped in `Arc<RwLock<HashMap<String, ClientViewState>>>`.
    - Methods: `register(client_id)`, `unregister(client_id)`, `update_viewport(client_id, cols, rows)`, `set_focus(client_id, pane_id)`, `set_scroll(client_id, pane_id, offset)`, `get(client_id)`.
  - In `src/api/ws.rs`:
    - Link WebSocket connection lifetime to `ClientViewRegistry`.
    - Ensure client focus change updates `ClientViewState` without invoking `WindowManager::focus_pane(id)` on the main TUI.
</task>

<task id="60-02-02" name="SEC-R01 Static SPA Server & CORS Configuration (src/api/static_serve.rs)">
Implement static asset serving and SPA routing under strict filesystem confinement (`WEB-FE-04`, `SEC-R01`).
- In `src/config.rs`:
  - Add optional CLI/config flags:
    - `web_dir: Option<PathBuf>` (`--web-dir <PATH>`).
    - `cors_origin: Option<String>` (`--cors-origin <ORIGIN>`).
- In `src/api/static_serve.rs`:
  - Implement MIME type mapper (`.html`, `.js`, `.mjs`, `.css`, `.svg`, `.png`, `.jpg`, `.woff2`, `.json`, `.wasm`).
  - Implement path traversal security sanitizer (`SEC-R01`):
    - Canonicalize `web_dir` once at initialization (`root`).
    - Reject request paths containing `\0`, backslashes, or control characters.
    - Resolve relative target path, canonicalize, and verify `canonical_target.starts_with(&root)`.
    - If validation fails, return `403 Forbidden` or `404 Not Found`.
  - Implement SPA routing:
    - If target file exists and is a regular file, stream with proper `Content-Type` and `Cache-Control`.
    - If target file does not exist and path has no file extension (client-side route like `/agents` or `/workspace`), serve `index.html` with `200 OK` and `text/html`.
  - Implement CORS header middleware:
    - If `cors_origin` is set, attach `Access-Control-Allow-Origin: <origin>` and related headers.
    - Respond to HTTP `OPTIONS` requests with `204 No Content`.
  - In `src/api/http.rs`:
    - Integrate static file handler as the fallback arm for unmatched HTTP GET/HEAD requests.
</task>
