<task id="55-02-01">
<title>Add `Action::Daemon(DaemonOp)` and colon command parser/executor</title>
<description>
1. In `src/action.rs`:
   - Define `pub enum DaemonOp { List, Status { name: Option<String> }, Start { name: Option<String> }, Stop { name: Option<String>, force: bool }, Switch { name: String } }`.
   - Add `Action::Daemon(DaemonOp)` variant.
   - Update `Action::sample` and `every_action_is_reachable_from_keymap_colon_or_rpc`.
2. Create `src/colon_command/parse_daemon.rs`:
   - Parse `:daemon list`, `:daemon status [name]`, `:daemon start [name]`, `:daemon stop [name]`, `:daemon switch <name>`.
   - Wire hook into `src/colon_command/parse.rs`.
3. Create `src/colon_command/execute_daemon.rs`:
   - Implement `execute_daemon_command(wm: &mut WindowManager, op: &DaemonOp) -> ActionResult`.
   - Wire into `src/colon_command/execute_wm.rs`.
</description>
</task>

<task id="55-02-02">
<title>Implement JSON-RPC `daemon.*` methods and `bilterm_daemon` MCP tool</title>
<description>
1. Create `src/api/rpc_daemon.rs`:
   - `daemon.list`: returns JSON array of all registered daemons with active status.
   - `daemon.status`: returns detailed telemetry for named daemon.
   - `daemon.stop`: triggers graceful shutdown (checkpoint journal, clean sockets/locks).
   - `daemon.start`: auto-spawns background daemon if not already running.
   - `daemon.switch`: sets active daemon connection context.
2. In `src/api/rpc.rs`:
   - Route `"daemon.list" | "daemon.status" | "daemon.stop" | "daemon.start" | "daemon.switch"` to `rpc_daemon`.
3. In `src/api/mcp.rs`:
   - Add `bilterm_daemon` tool specification and dispatch logic.
4. In `src/daemon/mod.rs`:
   - Add `DaemonRequest::Handshake` and `DaemonResponse::VersionMismatch` wire variants.
   - Check `CARGO_PKG_VERSION` on connection and return actionable diagnostic on mismatch (`DAEM-08`).
</description>
</task>

<task id="55-02-03">
<title>Wire auto-spawn into `main.rs` and write Wave 2 integration tests</title>
<description>
1. In `src/main.rs`:
   - In `bilterm ctl`: if connection to socket fails with `NotFound` or `ConnectionRefused`, auto-dispatch the default singleton daemon via `DaemonSupervisor::ensure_started()`, wait up to 1 second for socket readiness, and retry request.
2. Create `tests/phase55_daemon_lifecycle.rs`:
   - Test auto-spawn on `bilterm ctl` when no daemon is active.

   - Test JSON-RPC `daemon.*` handlers.
   - Test MCP `bilterm_daemon` execution.
   - Test version mismatch handshake rejecting client with informative diagnostic.
   - Test graceful shutdown cleans up lockfiles and registry JSON.
3. Verify tests pass with `cargo test --test phase55_daemon_lifecycle -q`.
</description>
</task>
