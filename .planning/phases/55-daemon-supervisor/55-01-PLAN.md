<task id="55-01-01">
<title>Implement DaemonLock and stale-PID recovery in `src/daemon/supervisor.rs`</title>
<description>
Create `src/daemon/supervisor.rs` with `DaemonLock` and `DaemonLockRecord`:
1. Implement `DaemonLock::acquire(runtime_dir: &Path, name: &str) -> io::Result<DaemonLockResult>`:
   - Sanitizes and validates `name` using `validate_safe_name`.
   - Resolves lockfile path (`daemons/daemon-<name>.lock`, or `daemon-singleton.lock` for `"default"` / singleton).
   - Opens file with `O_RDWR | O_CREAT` (mode `0600`) inside verified `0700` directory.
   - Applies non-blocking exclusive flock (`libc::flock(fd, libc::LOCK_EX | libc::LOCK_NB)`).
   - If acquired: writes JSON `DaemonLockRecord { pid, name, version, started_at_ms, socket_path }` and retains the open file descriptor.
   - If blocked (`EWOULDBLOCK` / `EAGAIN`): reads existing `DaemonLockRecord`.
     - Probes process liveness via `libc::kill(record.pid, 0)`.
     - If PID is dead (`ESRCH`): unlinks stale socket and re-attempts lock acquisition (stale lock recovery).
     - If PID is alive: returns `DaemonLockResult::AlreadyHeld(record)`.
2. Implement `DaemonLock::release(&mut self)` to cleanly remove lockfile on graceful shutdown.
</description>
</task>

<task id="55-01-02">
<title>Implement DaemonRegistry in `src/daemon/registry.rs`</title>
<description>
Create `src/daemon/registry.rs`:
1. Define `DaemonRegistryEntry` with fields: `id`, `name`, `pid`, `version`, `started_at_ms`, `socket_path`, `sessions_count`, `panes_count`, `agents_count`, `last_heartbeat_ms`.
2. Implement `DaemonRegistry::register(base_dir: &Path, entry: &DaemonRegistryEntry) -> io::Result<()>`:
   - Writes atomic `0600` JSON into `<base_dir>/daemons/<name>.json`.
3. Implement `DaemonRegistry::update_heartbeat(base_dir: &Path, name: &str, sessions: usize, panes: usize, agents: usize) -> io::Result<()>`.
4. Implement `DaemonRegistry::list_active(base_dir: &Path) -> Vec<DaemonRegistryEntry>`:
   - Scans `<base_dir>/daemons/*.json`.
   - Verifies process liveness for each entry. If PID is dead, unlinks the `.json` file and cleans up dead socket (automatic pruning).
5. Implement `DaemonRegistry::unregister(base_dir: &Path, name: &str) -> io::Result<()>`.
</description>
</task>
