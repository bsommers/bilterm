## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| keyboard -> primary pane during connect | credentials typed for ssh |
| transport events -> state machine | stale or duplicate events from an old transport |
| profile / API target -> spawned `ssh` | a network process is started |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-----------|-----------------|
| T-51.1-20 | Elevation of Privilege | connecting to an arbitrary destination through API or colon | high | mitigate | destination validated before any pane or process; argv from plan 02 (no injection); same capability as existing `:ssh` / `remote.connect_ssh`; one link at a time |
| T-51.1-21 | Tampering | stale events from a previous transport acting on the new connection, or a double report of one drop | medium | mitigate | `generation` counter and a once-per-generation report flag; tests `reports_once_per_generation` |
| T-51.1-01 | Information Disclosure | password typed during connect reaching history | high | mitigate | raw link input while awaiting control; test `typed_password_never_reaches_history` |
| T-51.1-SC | Tampering | cargo installs | high | mitigate | no dependency change |
</threat_model>
