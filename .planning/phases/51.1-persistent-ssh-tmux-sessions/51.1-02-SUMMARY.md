# Phase 51.1 Plan 02: SSH argv builder / remote options Summary

BASE `7604bdf` (tip of `feat/navigator-rows-and-launch` / branch `agy/511-02`). Implement PST-01 and PST-04: keepalive options on both builders, `-tt` and no multiplexing for persistent tmux-CC links, login-shell wrapper with Homebrew/MacPorts PATH on macOS, shortened `ControlPersist=10s` for `:ssh` panes, and `redact_ssh_argv` for safe logging without leaking keys or socket paths.

## Key Changes

1. **`src/remote/mod.rs`**:
   - `push_keepalive_args`: pushes `-o ServerAliveInterval=15 -o ServerAliveCountMax=3 -o TCPKeepAlive=yes -o ConnectTimeout=15`.
   - `push_common_args`: parameterized by `is_link: bool`. For persistent links (`is_link = true`), emits `-o ControlMaster=no -o ControlPath=none` regardless of `control_dir` or `control_master`. For `:ssh` panes (`is_link = false`), emits `ControlMaster=auto`, `ControlPersist=10s` (shortened from `60s`), and `ControlPath` when a safe directory is provided.
   - `build_ssh_tmux_cc_args`: starts with `-tt` (replacing `-T`), validates destination first, appends keepalive and no-mux flags, `--`, destination, and the single remote login-shell argument: `exec $SHELL -lc 'exec env PATH="$PATH:/opt/homebrew/bin:/usr/local/bin:/opt/local/bin" tmux -CC new-session -A -s NAME'`. NAME sanitizes session to `[A-Za-z0-9_-]` (fallback `bilterm`), guaranteeing exactly two single quotes and zero injection vectors.
   - `redact_ssh_argv`: safely redacts `-i <key>` and `ControlPath=<private>` for structured tracing.
   - Updated in-file test `tmux_args_place_double_dash_before_destination`.
2. **`tests/full_suite_battle_and_perf.rs`**:
   - Updated assertions in `unit_exhaustively_covers_remote_profiles_fleet_selectors_and_snapshots` to check `-tt` instead of `-T`, `contains("-s prodmain")` / `contains("-s bilterm")`, and `!contains("ControlMaster=auto")`.
3. **`tests/phase51_1_ssh_argv.rs`**:
   - 9 new headless unit and integration tests covering `-tt`, keepalive, login shell wrapper, macOS PATH, session sanitisation with quote counting, option injection rejection, `:ssh` keepalive + short persist, absence of control flags without safe control dir, and argv redaction.
