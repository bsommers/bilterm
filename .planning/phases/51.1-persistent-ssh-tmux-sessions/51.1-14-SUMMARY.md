# Phase 51.1 Plan 14: Documentation and Coverage Gate Summary

BASE `ab25848` on branch `agy/511-14`. Documented the shipped persistent SSH + tmux link behaviour across all user guides, reference tables, troubleshooting, security guidelines, JSON-RPC/MCP API reference, developer engineering guide, and changelog, backed by a dedicated coverage gate script.

## Key Changes

1. **Chapter 05 (First-Class `tmux` Integration)**:
   - Replaced false claims with real behaviour: `ssh -tt` child process, frozen SSH options (`ServerAliveInterval=15`, `ServerAliveCountMax=3`, `TCPKeepAlive=yes`, `ConnectTimeout=15`, `ControlMaster=no`, `ControlPath=none`), login-shell wrapper with macOS Homebrew/MacPorts `$PATH` (`/opt/homebrew/bin`, `/usr/local/bin`, `/opt/local/bin`).
   - Documented interactive connect phase, raw password security, link states (`idle`, `connecting`, `connected`, `reconnecting`, `detached`, `ended`, `failed`) and banners, deterministic capped exponential backoff (1/2/4/8/16/30s up to 20 attempts), `capture-pane` hydration, single-link constraint, and remote `tmux` options (`exit-empty`, `destroy-unattached`, `detach-on-destroy`).

2. **Chapter 06 (Keyboard, Mouse & Command Reference)**:
   - Added command table rows for `:ssh-tmux <user@host> [session]`, `:ssh-tmux reconnect`, `:ssh-tmux disconnect`, `:ssh-tmux info`, and `:ssh-tmux prefill`.
   - Documented key chords: `Ctrl+Alt+R`, `<L> u`, `<L> U`, `<L> Q`.
   - Added interactive link banner key bindings: `Enter`/`r` (reconnect), `x` (disconnect), `d` (detach).
   - Documented top menu bar Tmux items and banner row mouse click actions.

3. **Chapter 07 (Troubleshooting & FAQ)**:
   - Added troubleshooting section for early disconnects / odd reconnects based on root cause diagnosis.
   - Listed `RUST_LOG=bilterm=debug` usage, `bilterm.log` location, structured `bilterm::link` tracing events (`link.connect`, `link.up`, `link.down`, `link.retry`, `link.give_up`, `link.control_exit`, `link.spawn_failed`, `link.hydrate`, `pane.exit`), `tmux ls`, `~/.tmux.conf`, Mac `pmset -g` sleep/keepalive settings, and `(not connected)` restore honesty.

4. **Chapter 10 (Security Architecture & Operational Best Practices)**:
   - Documented persistent link security properties: no secrets on argv or in logs (`redact_ssh_argv`), host keys never auto-accepted, fresh TCP connection per reconnect, typed passwords bypassing prompt/history/find buffers, and strict wrapper shell argument quoting.

5. **Chapter 12 (Find Registry and History)**:
   - Updated G1 and G2 rows from documented gaps to resolved in Phase 51.1.

6. **API Reference (`docs/API.md`)**:
   - Added `remote.link` method specification (`op?: "status" | "reconnect" | "disconnect"`), response schema with full `link` object (`LinkSummary`), and error codes.
   - Updated `remote.connect_tmux` / `remote.connect_ssh` result descriptions and JSON example to report `status: "connecting"`.
   - Added `bilterm_remote_link` to master MCP tools table and bumped tool count from 13 to 14.

7. **Developer Guide (`docs/DEVELOPER_AND_AGENT_GUIDE.md`)**:
   - Updated source tree and module boundaries with new Phase 51.1 modules.
   - Added Section 6d detailing the module map, state machine, tick order in `tick_tmux_link`, headless testing architecture (`WindowManager::new_headless`, `from_channels`, test connector/driver, fake clock), and integration test suites.

8. **Changelog (`CHANGELOG.md`)**:
   - Added comprehensive Unreleased entry summarizing PST-01..04, UNI-R01, and behavioral changes.

9. **Doc Coverage Gate (`scripts/check_phase51_1_doc_coverage.sh`)**:
   - Automated gate checking all verbs, key chords (derived from `keymap.rs`), events, security properties, API entries, and forbidden patterns (`spawn_remote_ssh_attach_or_new`, `StrictHostKeyChecking=no`). Supports `PHASE51_1_DOCS_PART=1`.
