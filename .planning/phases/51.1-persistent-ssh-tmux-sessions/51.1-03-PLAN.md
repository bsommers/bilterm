Build the byte-level transport for PST-01/PST-02: a DCS-aware splitter that separates the interactive pre-control text (ssh banners, host-key and password prompts) from tmux control lines, and a PTY-backed driver that connects a real `ssh -tt` child to the channel pair `TmuxControlSubprocess::from_channels` already understands.

Purpose: `tmux -CC` needs a tty on the client side (debug 6a); the bridge consumes lines; users must be able to answer ssh prompts. This plan joins them without touching the bridge.
Output: `splitter.rs`, `transport.rs`, `PtySession::exit_code`, tests.
</objective>
