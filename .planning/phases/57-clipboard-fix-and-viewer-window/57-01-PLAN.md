1. In `src/clipboard.rs`:
   - Define `#[derive(Debug, Clone, PartialEq, Eq)] pub enum ClipboardMimeProbe { Text, Media { mime: String, bytes_len: usize }, Empty }`.
   - Add a thread-local / global `Mutex<Option<ClipboardMimeProbe>>` test override `pub fn set_test_clipboard_mime_override(probe: Option<ClipboardMimeProbe>)` so integration tests can simulate image/video vs text clipboard states deterministically without an X11/Wayland display.
   - Implement `pub fn probe_system_clipboard_mime() -> ClipboardMimeProbe`:
     - Check test override first; if `get_test_clipboard_override().is_some()`, return `ClipboardMimeProbe::Text`.
     - On Linux Wayland (`WAYLAND_DISPLAY` set): run `wl-paste --list-types` with 80ms timeout; if output contains `image/png`, `image/jpeg`, `image/webp`, `image/gif`, or `video/`, return `ClipboardMimeProbe::Media { mime, bytes_len: 0 }`.
     - On Linux X11 (`DISPLAY` set): run `xclip -selection clipboard -t TARGETS -o` with 80ms timeout; if output contains `image/png`, `image/jpeg`, `image/webp`, `image/gif`, or `video/` (and does not only advertise `UTF8_STRING`/`TEXT`/`STRING`), return `ClipboardMimeProbe::Media { mime, bytes_len: 0 }`.
     - On macOS: run `osascript -e "clipboard info"` (80ms timeout); if it contains `«class PNGf»` or `TIFF picture` without `Unicode text`/`string`, return `ClipboardMimeProbe::Media`.
     - Otherwise, if `get_system_clipboard()` returns `Some(s)` with `!s.is_empty()`, return `ClipboardMimeProbe::Text`, else `ClipboardMimeProbe::Empty`.
2. In `src/vt/scan_osc_dcs.rs`:
   - Add a pure helper `decode_osc52_payload(osc_body: &str) -> Option<String>` that parses `52;<selection>;<base64_payload>`, ignores queries (`?`), base64-decodes valid UTF-8 payloads (up to 1 MiB cap per `bounding-untrusted-resource-use`), and pushes decoded strings to a new `pending_osc52_decoded: Vec<String>` queue on `VtParser` (with `pub fn take_osc52_decoded(&mut self) -> Vec<String>`).
3. In `src/pane/mod.rs`:
   - During `poll_pty` / VT output processing, drain `vt.take_osc52_decoded()`: for each decoded string, call `crate::clipboard::set_system_clipboard(&text)` and `self.prompt.push_yank(text.clone())`, plus queue a pane-level `pending_clipboard_events: Vec<(ClipboardSource, String)>` so `WindowManager` records it in `ClipboardRegistry` with `ClipboardSource::Osc52Inbound`.
