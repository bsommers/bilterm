<objective>
Implement Wave 1 (`VIEW-01`): Pure Squarified Treemap Layout Engine.
Develop a pure, deterministic 2D squarified treemap packing algorithm tailored for terminal character grids, supporting multi-session packing, nested sessions, character-cell aspect ratio correction, and zero-panic graceful degradation.
</objective>

<tasks>
1. Define the layout models in `src/wm/session_pack_layout.rs`:
   - `SessionPackInput`, `WindowPackInput`
   - `SessionPackLayout`, `SessionLayoutBox`, `WindowLayoutBox`
   - Bounded weight sanitization and label sanitization integration (`sanitize_display`).
2. Implement squarified treemap packing in `src/wm/session_pack_layout.rs`:
   - Formulate terminal cell aspect ratio penalty $\rho(w, h) = \max(\frac{w}{2h}, \frac{2h}{w})$.
   - Implement strip-based squarified partitioning with deterministic tie-breaking.
   - Allocate session container borders (`outer_rect`, header, `inner_rect`).
   - Implement recursive packing for nested child sessions.
   - Implement graceful degradation logic for small (`outer_rect < 6x3`) and tiny areas (`area < 10x4`).
   - Ensure all arithmetic uses `saturating_add`, `saturating_sub`, and clamping to prevent overflow.
3. Expose module in `src/wm/mod.rs` and author comprehensive test suite in `tests/phase54_packing_layout.rs`:
   - Determinism test: Multiple executions with identical input vectors yield identical box coordinates.
   - Containment test: All windows $\subseteq$ session inner rect $\subseteq$ outer rect $\subseteq$ bounding area.
   - Non-overlap test: Pairwise intersection checks for sibling containers and sibling windows.
   - Nested sessions test: Multi-level session hierarchy verification.
   - Stress & boundary test: Degenerate rects (`0x0`, `1x1`, `2x2`, `100x1`, `1x100`, 0 sessions, 100 sessions).
</tasks>
