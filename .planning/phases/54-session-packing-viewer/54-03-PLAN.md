<objective>
Implement Wave 3 (`VIEW-03`, `VIEW-04`, `UNI-R01`): Drag-and-Drop, Keyboard Equivalents, and Surface Parity.
Implement mouse drag-and-drop for windows across session containers in the Packing Viewer and across session nodes in the Navigator tree, full keyboard pickup/drop workflows, declarative keymap entries, colon command parity, automation API exposure, and comprehensive E2E parity tests.
</objective>

<tasks>
1. Implement pure mouse planning and drag handling in `src/input/session_map.rs`:
   - Pure function `plan_session_map_mouse(wm: &WindowManager, mouse: MouseEvent, ws: Rect) -> Option<SessionMapMousePlan>` returning actions, drag updates, and swallow flags.
   - Hit testing: `SessionMapHit` for window cards, session container drop zones, title bar, resize borders, and chrome buttons.
   - Drag states: `SessionMapDrag::WindowDrag` tracking `window_id`, `source_session`, `current_x`, `current_y`, `target_session`.
   - Drop lowering: Valid drop emits `Action::WindowMove { window_id, target_session_id }`; invalid drop is safe no-op.
   - Drag cancellation on `Esc` or release outside.
2. Implement Navigator tree drag-and-drop in `src/input/drawer_navigator.rs`:
   - Extend Navigator mouse drag handling to recognize dragging window rows across session headers.
   - Highlight candidate target session row during drag.
   - Lower valid drops to `Action::WindowMove`.
3. Implement in-window keyboard workflow and declarative keymap:
   - `src/input/session_map_keys.rs`: Navigation (`h`/`j`/`k`/`l`, arrows), pickup (`Space`/`m`), target selection (`Tab`/arrows), drop (`Enter`), cancel (`Esc`), pin (`*`), dock (`d`), and scale (`[`/`]`).
   - Add global toggle chord to `src/input/keymap.rs` (`DEFAULT_LEADER_BINDINGS`, e.g. Leader `S` or `Ctrl+Alt+M`).
   - Wire `:sessions map pickup|target|drop|cancel` colon subcommands.
   - Expose `session.map` and `window.move` via JSON-RPC (`src/api/rpc/mod.rs`) and MCP (`src/api/mcp/mod.rs`).
4. Author comprehensive test suite in `tests/phase54_drag_drop_parity.rs`:
   - Test mouse drag-and-drop success and target container highlight.
   - Test mouse drag-and-drop cancellation on `Esc` and out-of-bounds drops.
   - Test keyboard pickup, target cycling, drop, and cancel workflows.
   - Test surface parity: Assert that mouse drag, keyboard pickup/drop, `:sessions map` commands, and RPC calls yield identical window-manager and session tree states.
   - Test Navigator drawer drag-and-drop integration.
</tasks>
