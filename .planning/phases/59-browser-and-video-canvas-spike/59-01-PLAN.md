<task id="59-01-01">
<title>Create `src/pane/browser_canvas/{mod,cdp,chrome_ui}.rs` with `BrowserEngine` and `CdpBrowserBackend`</title>
<description>
1. Create `src/pane/browser_canvas/mod.rs`:
   - Define `MediaRgbaFrame`, `MediaMouseEvent`, `MediaMouseEventKind`, and `BrowserEngine` trait.
   - Define `BrowserCanvasState` holding `Box<dyn BrowserEngine>`, `viewport_focused: bool`, `zoom_pct: u16`, `history: Vec<String>`, `history_idx: usize`, and `cached_frame: Option<MediaRgbaFrame>`.
   - Implement `SyntheticBrowserBackend` that renders an anti-aliased RGBA preview card (page title, URL, DOM summary, interactive cursor/scroll offset) up to `1920x1080` so tests and headless environments without Chrome work deterministically.
2. Create `src/pane/browser_canvas/cdp.rs`:
   - Implement `discover_chromium_binary() -> Option<PathBuf>` probing `BILTERM_CHROME_PATH` and standard Linux/macOS/Windows Chrome/Chromium/Brave/Edge paths.
   - Implement `CdpBrowserBackend`:
     - Allocates a private `0700` profile directory via `secure_fs::ensure_private_dir`.
     - Spawns Chromium with `--headless=new`, `--hide-scrollbars`, `--no-first-run`, `--user-data-dir=<dir>`, and local debugging transport; kills child cleanly on `Drop`.
     - Sends `Page.navigate`, `Page.startScreencast`, `Page.screencastFrameAck`, `Emulation.setDeviceMetricsOverride`, `Input.dispatchMouseEvent`, and `Input.dispatchKeyEvent`.
     - Automatically falls back to `SyntheticBrowserBackend` if no Chromium binary is found or when `url.starts_with("about:")` / `url.starts_with("demo://")` in headless test mode.
3. Create `src/pane/browser_canvas/chrome_ui.rs`:
   - Render the 1-row top Browser Navigation Bar (`[◄] [►] [↻] [URL/Title] [FOCUS/PROMPT] [✕]`) into a Ratatui `Buffer` row.
   - Provide pure hit-testing `hit_test_browser_nav_bar(nav_rect: Rect, col: u16, row: u16) -> Option<BrowserNavHit>` for mouse clicks on Back, Forward, Reload, Focus toggle, and Close.
</description>
</task>
