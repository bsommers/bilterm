<task id="59-02-01">
<title>Create `src/pane/video_canvas/{mod,ffmpeg,osd}.rs` with `VideoPlayerEngine` and `VideoFrameRing`</title>
<description>
1. Create `src/pane/video_canvas/mod.rs`:
   - Define `VideoPlaybackSnapshot { source, playing, position_secs, duration_secs, volume_pct, muted, looping, speed, width_px, height_px, frame_seq, backend_name }`.
   - Define `VideoFrameRing` (bounded 3-slot ring buffer capped at `1920x1080x4` bytes) and `VideoPlayerEngine` trait.
   - Implement `SyntheticVideoBackend` supporting animated `demo://smpte` (SMPTE color bars + moving timecode/ball) and `demo://plasma` so tests and headless environments run at 60fps without requiring external media files.
2. Create `src/pane/video_canvas/ffmpeg.rs`:
   - Implement `FfmpegPipeBackend`:
     - Probes media duration, dimensions, and FPS via `ffprobe` when available.
     - Spawns `ffmpeg -nostdin -loglevel error -ss <pos> -re -i <path> -vf scale=<w>:<h>:flags=fast_bilinear -pix_fmt rgba -f rawvideo -` into a background reader thread feeding `VideoFrameRing`.
     - Spawns optional companion `ffplay -nodisp -vn -autoexit -loglevel quiet -ss <pos> -volume <vol> <path>` when unmuted and audio stream is present; kills both child processes deterministically on pause, seek, close, or `Drop`.
     - Falls back to `SyntheticVideoBackend` for `demo://*` URIs or when `ffmpeg` is not installed.
3. Create `src/pane/video_canvas/osd.rs`:
   - Render the 1-row bottom OSD Transport Bar (`[▶/⏸] [⏮] [⏭] [━━●─── 01:24/03:50] [🔊 100%] [1.0x] [🔁] [✕]`) into a Ratatui `Buffer` row.
   - Provide pure hit-testing `hit_test_video_osd_bar(osd_rect: Rect, col: u16, row: u16) -> Option<VideoOsdHit>` including exact scrub-bar click percentage (`0..=100`).
</description>
</task>
