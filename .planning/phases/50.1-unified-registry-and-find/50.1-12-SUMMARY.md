## Behaviour
- Live agent/pane row: `focus_and_raise`, close, `Jumped to #N (live)`; vanished pane: `pane #N is gone`, window stays open; `metadata_only` row: focus plus "no remote tmux is attached".
- Session rows: live closes; saved row calls `switch_or_create_session` and says the outgoing session was autosaved (or that autosave is off); log-only row says `session <name> has history only (no saved layout)` and stays open. Saved pane rows switch, then focus the pane id if present.
- History rows: live pane found and focused, scrolled to the newest matching command block; otherwise the command goes into the active prompt (never PTY, never submitted, `prompt.history` unchanged). Hidden prompt: says so, nothing placed, window stays open.
- No selected row: `Find: no result selected`.
