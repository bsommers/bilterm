Rules (50.1-CONTRACT.md section 9 is authoritative; summary):
(a) `NAME=value` with a secret-ish NAME (password, passwd, secret, token, apikey, api_key, api-key, credential, private_key, access_key; case-insensitive substring of NAME) and a non-empty value; also after `export`/`set`/`env`/inline prefix assignments.
(b) flags `--password --passwd --token --secret --api-key --apikey --auth-token --client-secret --access-key --passphrase` followed by a value (next word) or `=value`.
(c) `-p<value>` attached form only when the first word is mysql/mariadb/mysqldump/mysqladmin/sshpass; `sshpass -p <word>`.
(d) `Authorization:`, `Proxy-Authorization:`, `X-Api-Key:` headers (case-insensitive) with a value, `Bearer <token>`.
(e) URL userinfo `scheme://user:password@host`.
(f) token shapes: `ghp_ gho_ ghs_ github_pat_` + >= 20 [A-Za-z0-9_]; `sk-` + >= 20 [A-Za-z0-9_-]; `AKIA` + 16 [0-9A-Z]; `xox[abprs]-`; `AIza` + 35 [A-Za-z0-9_-]; JWT `eyJ<b64>.eyJ<b64>.`; `-----BEGIN ... PRIVATE KEY-----`.
(g) `openssl ... -passin/-passout pass:..`, `gpg --passphrase`, `chpasswd`, `htpasswd -b`, and `echo|printf ... | sudo -S`.
Not secrets: `grep -r password src/`, `git commit -m "rotate token"`, `echo password`, `cargo test token_refresh`, `ls ~/.ssh`.
</context>
