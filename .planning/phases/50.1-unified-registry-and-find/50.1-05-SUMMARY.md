# Phase 50.1 Plan 05: history.log meta fields and exit annotations Summary

`history.log` command lines can now carry percent-encoded `host=`/`transport=`/`cwd=` fields, and a separate `~exit | ... | h=<fnv1a-32> | exit=<n>` annotation line records exit codes by hash only; `load_entries_annotated` joins them per `(run, pane, hash)`, legacy readers are untouched.

## What changed

- `HistoryStore::record_command` delegates to `record_command_meta(cmd, &HistoryMeta::default())`; default output is byte-identical (tested by comparing two stores modulo timestamp).
- New private helpers: `percent_encode_field`/`percent_decode_field` (safe set `[A-Za-z0-9._~/@:+-]`), `fnv1a_32_hex`, `parse_annotation`, `append_line` (shared 0600 append + count + compaction).
- `parse_history_line`, `HistoryEntry`, `load_entries`, and all pre-existing tests are unchanged (test file diff is 268 added lines, 0 deleted).
- `history_store.rs`: 676 -> 882 lines (limit 900).
