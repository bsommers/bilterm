# Phase 28 Plan 01: Architecture Review Remediation, Module DAG Decoupling & Runtime Efficiency

## Objective
Execute the prioritized remediation roadmap from [`docs/ARCHITECTURE_REVIEW.md`](../../../docs/ARCHITECTURE_REVIEW.md) across three waves:
- **Wave 1 (P0 + P1 Foundation — Completed 2026-10-25)**:
  - [x] **P0.1**: Confine `:canvas export <path>` under `SnapshotPolicy::Confined` (`validate_snapshot_name` + `secure_fs::write_private_file`) across RPC/MCP/Playbook control planes.
  - [x] **P0.2**: Cache `probe_terminal_pixel_size()` (`TIOCGWINSZ`) in `CACHED_TERMINAL_PIXELS` (refreshed on `Event::Resize`), wire `CanvasResolution` into live TUI `render_graphical_canvas`, and use actual pane `(cols, rows)` in `:canvas export` and `:canvas encode`.
  - [x] **P1.1 (Part A)**: Extract `handle_rpc_canvas` and `handle_rpc_fontsize` into `src/api/rpc_handlers.rs`, eliminating the `ui -> api` dependency cycle.
  - [x] **P1.2 (Part A)**: Decompress near-ceiling modules (`src/colon_command/execute.rs` $\rightarrow$ `299` LOC + `execute_wm.rs` `495` LOC; `src/pane/mod.rs` $\rightarrow$ `677` LOC + `src/pane/tests.rs`; `src/wm/z_stack.rs` $\rightarrow$ `611` LOC + `src/wm/tests.rs`).
  - [x] **Supply Chain**: Set `default-features = false` on `vt100-ctt`, pruning 13 unused crates and eliminating `RUSTSEC-2024-0436` (`paste`) and `RUSTSEC-2026-0002` (`lru 0.12.5`).
- **Wave 2 (P1 Complete — Layer DAG & Prompt Encapsulation)**:
  - [ ] **P1.1 (Part B)**: Move value/domain types (`FontFamilyPreset`, `PaneFontOptions`, `LineSizeAttr`, `CanvasResolution`) out of `src/ui/` into `src/pane/` and `src/vt/` so `pane`, `vt`, and `config` have zero upward imports from `src/ui/`.
  - [ ] **P1.2 (Part B)**: Split `src/colon_command/parse.rs` (`732` LOC) by command domain and `src/vt/scan.rs` (`776` LOC) into single-pass CSI/OSC/DCS sub-scanners.
  - [ ] **P1.3**: Encapsulate `FloatingPromptState` fields in `src/pane/prompt_editor.rs` behind invariant-enforcing methods.
- **Wave 3 (P2 & P3 — Dirty-Driven Redraw, Cached Rasterization & `VtWorkerHandle` Wiring)**:
  - [ ] **P2.1**: Add generation-based dirty tracking in `App::run` and cache rasterized `PixelCanvasBuffer` frames on `(scene_gen, tek_gen, width, height, resolution, cursor)`.
  - [ ] **P2.2**: Replace 14-pass `match_indices` scanning in `scan_control_sequences` with a single-pass `ESC` state machine.
  - [ ] **P3.1 & P3.2**: Wire `VtWorkerHandle` (`tokio::sync::watch<Arc<GridSnapshot>>`) into live `CompositePane` and enforce module DAG acyclicity in `tests/vt_worker_and_snapshot_seam.rs`.
