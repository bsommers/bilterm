# Phase 28 Plan 01: Architecture Review Remediation, Module DAG Decoupling & Runtime Efficiency

## Objective
Execute the prioritized remediation roadmap from [`docs/ARCHITECTURE_REVIEW.md`](../../../docs/ARCHITECTURE_REVIEW.md) across three waves:
- **Wave 1 (P0 + P1 Foundation — Completed 2026-10-25)**:
  - [x] **P0.1**: Confine `:canvas export <path>` and `:record start <path>` under `SnapshotPolicy::Confined` (`validate_plain_file_name` + `secure_fs::write_private_file`) across RPC/MCP/Playbook control planes.
  - [x] **P0.2**: Cache `probe_terminal_pixel_size()` (`TIOCGWINSZ`) in `CACHED_TERMINAL_PIXELS` (refreshed on `Event::Resize`), wire `CanvasResolution` into live TUI `render_graphical_canvas`, and use actual pane `(cols, rows)` in `:canvas export` and `:canvas encode`.
  - [x] **P1.1 (Part A)**: Extract `handle_rpc_canvas` and `handle_rpc_fontsize` into `src/api/rpc_handlers.rs`, eliminating the `ui -> api` dependency cycle.
  - [x] **P1.2 (Part A)**: Decompress near-ceiling modules (`src/colon_command/execute.rs` $\rightarrow$ `298` LOC + `execute_wm.rs` `505` LOC; `src/pane/mod.rs` $\rightarrow$ `677` LOC + `src/pane/tests.rs`; `src/wm/z_stack.rs` $\rightarrow$ `611` LOC + `src/wm/tests.rs`).
  - [x] **Supply Chain**: Set `default-features = false` on `vt100-ctt`, pruning 13 unused crates and eliminating `RUSTSEC-2024-0436` (`paste`) and `RUSTSEC-2026-0002` (`lru 0.12.5`).
- **Wave 2 (P1 Complete — Layer DAG & Prompt Encapsulation — Completed 2026-10-25)**:
  - [x] **P1.1 (Part B)**: Move value/domain types (`FontFamilyPreset`, `PaneFontOptions`, `LineSizeAttr`, `scan_dec_line_size_escapes`, `CanvasResolution`, `Osc133Phase`) into `src/pane/typography.rs`, `src/vt/snapshot.rs`, and `src/pty/line_discipline.rs` so `pty`, `vt`, and `pane` form a strict 0-cycle DAG with zero upward imports from `src/ui/` or `src/config/`.
  - [x] **P1.2 (Part B)**: Split `src/colon_command/parse.rs` (`732` $\rightarrow$ `412` LOC + `src/colon_command/parse_visual.rs` `338` LOC) and `src/vt/scan.rs` (`776` $\rightarrow$ `352` LOC + `src/vt/scan_osc_dcs.rs` `378` LOC).
  - [x] **P1.3**: Encapsulate `FloatingPromptState` buffer/cursor fields (`input`, `lines`, `cursor_row`, `cursor_col`, `cursor_char_idx`, `scroll_offset`, `h_scroll_offset`, `history_index`) as `pub(crate)` behind read-only getters in `src/pane/prompt_editor.rs`.
- **Wave 3 (P2 & P3 — Dirty-Driven Redraw, Cached Rasterization & CI DAG Gates — Completed 2026-10-25)**:
  - [x] **P2.1**: Add dirty-driven `needs_redraw` tracking in `App::run` (`WindowManager::poll_all_ptys(&mut self) -> bool`) and cache rasterized `Arc<PixelCanvasBuffer>` frames on `RasterCacheKey` in `src/ui/canvas_raster.rs`.
  - [x] **P2.2**: Replace 14-pass `match_indices` scanning in `scan_control_sequences` (`src/vt/scan.rs`) with a single-pass `ESC` (`\x1b`) state machine and fast-path early return when no `0x1b` byte is present.
  - [x] **P3.2**: Enforce module DAG acyclicity (`pty -> vt -> pane` zero upward imports from `wm`, `ui`, `api`, `config`; `ui` zero imports from `api`) in `tests/vt_worker_and_snapshot_seam.rs`.
