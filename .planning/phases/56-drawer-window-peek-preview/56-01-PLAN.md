<task type="auto">
  <name>Task 2: Implement target resolution, snapshot caching, non-destructive preview ops, and `commit_drawer_preview`</name>
  <files>src/wm/drawer/ops.rs, src/wm/drawer/nav.rs</files>
  <action>
1. In `src/wm/drawer/ops.rs`:
   - Implement `pub fn resolve_drawer_preview_target(&self) -> Option<DrawerPreviewTarget>` on `WindowManager`:
     - If `self.drawer.preview.override_target` is `Some(target)`, validate that the referenced pane/session still exists and return it.
     - Otherwise, inspect the row at `self.drawer.selected_index` (using `navigator_drawer_rows_with_meta` in `Navigator` style or `classic_drawer_rows` in `Classic` style):
       - `DrawerRowKind::Pane(id)`: if `meta.session_name` is `Some(bg_session)` and `bg_session != self.history_session`, return `Some(DrawerPreviewTarget::BackgroundPane { session_name: bg_session, pane_id: id })`; else if `self.panes.contains_key(&id)`, return `Some(DrawerPreviewTarget::ActivePane(id))`.
       - `DrawerRowKind::QuickTerminal`: return `Some(DrawerPreviewTarget::QuickTerminal)`.
       - `DrawerRowKind::SavedSession(name)`:
         - If `name == self.history_session`, return `Some(DrawerPreviewTarget::ActivePane(self.active_pane_id))`.
         - Else if `let Some(bg) = self.window_manage.background_sessions.get(&name)`, return `Some(DrawerPreviewTarget::BackgroundPane { session_name: name, pane_id: bg.active_pane_id })`.
         - Else return `Some(DrawerPreviewTarget::SavedSession { session_name: name })`.
       - `DrawerRowKind::GroupHeader(_)`: return `None`.
   - Implement `pub fn sync_drawer_preview_cache(&mut self)` on `WindowManager` to populate `self.drawer.preview.cached_session_snapshot` via `self.load_session_snapshot_any(&session_name)` whenever the resolved target is `DrawerPreviewTarget::SavedSession { session_name }` and the cached name differs.
   - Update `drawer_select_next`, `drawer_select_prev`, and `drawer_scroll_by` in `src/wm/drawer/ops.rs`, and `apply_drawer_nav_op` (`Next`, `Prev`, `Scroll`) in `src/wm/drawer/nav.rs`:
     - Clear `self.drawer.preview.override_target = None`.
     - If `self.config.drawer.auto_preview_on_scroll` is `true` and `self.drawer.open` is `true`, set `self.drawer.preview.active = self.resolve_drawer_preview_target().is_some()` and call `self.sync_drawer_preview_cache()`.
   - Implement `pub fn commit_drawer_preview(&mut self) -> Result<()>` and `pub fn execute_drawer_preview_op(&mut self, op: DrawerPreviewOp) -> Result<()>`:
     - `DrawerPreviewOp::On`: ensure `self.drawer.open = true`, set `self.drawer.preview.active = true`, `self.sync_drawer_preview_cache()`.
     - `DrawerPreviewOp::Off`: set `self.drawer.preview.active = false`, `self.drawer.preview.override_target = None`.
     - `DrawerPreviewOp::Toggle`: if `self.drawer.preview.active` is `true`, turn off; else turn on (opening drawer if closed).
     - `DrawerPreviewOp::Pane(id)`: set `override_target = Some(DrawerPreviewTarget::ActivePane(id))`, `self.drawer.preview.active = true`.
     - `DrawerPreviewOp::Session(name)`: resolve to `BackgroundPane` (if in `background_sessions`) or `SavedSession`, set `override_target`, `self.drawer.preview.active = true`, `self.sync_drawer_preview_cache()`.
     - `DrawerPreviewOp::Commit`: resolve target; for `ActivePane(id)` call `self.z_stack.unminimize(id)` + `self.focus_pane(id)`; for `QuickTerminal` make quick terminal visible and focused; for `BackgroundPane { session_name, pane_id }` call `self.switch_session(&session_name)?` then `self.z_stack.unminimize(pane_id)` + `self.focus_pane(pane_id)`; for `SavedSession { session_name }` call `self.switch_session(&session_name)?`; finally call `self.close_drawer()`.
   - Also update `DrawerNavOp::Activate` in `src/wm/drawer/nav.rs` and `drawer_activate_selected` in `src/wm/drawer/ops.rs` so pressing `Enter` on a background session's child `Pane(id)` row in Navigator switches to that session and focuses `id` (`commit_drawer_preview`).
  </action>

</task>
