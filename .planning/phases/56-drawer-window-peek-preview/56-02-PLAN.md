   - Implement `pub fn render_drawer_preview_overlay(wm: &WindowManager, area: Rect, buf: &mut Buffer)`:
     - Obtain `let Some(rect) = wm.drawer_preview_rect(area) else { return; };` and `let Some(target) = wm.resolve_drawer_preview_target() else { return; };`.
     - Clear/occlude `rect` with `occlude_rect(buf, rect, wm.config.visual.backdrop_Style, theme.workspace_bg)` and draw Borland drop shadow (`render_drop_shadow`) or Modern Liquid Glass halo (`render_glass_halo`).
     - Render outer border and top title banner:
       - Left banner text: ` 👁 PEEK PREVIEW: #<id> <title> [<state_badge>] ` where `<state_badge>` indicates `LIVE`, `MINIMIZED`, `STACKED`, `BG: <session>`, or `SAVED SESSION`.
       - Right banner badges: `[⏎/Click: Focus] [×]`.
       - Export helper geometry functions `pub fn preview_close_badge_rect(preview_rect: Rect) -> Rect` and `pub fn is_preview_close_click(preview_rect: Rect, col: u16, row: u16) -> bool` for mouse hit-testing in Wave 3.
     - Compute `inner_rect = Rect { x: rect.x + 1, y: rect.y + 1, width: rect.width.saturating_sub(2), height: rect.height.saturating_sub(2) }`:
       - `DrawerPreviewTarget::ActivePane(id)`: look up `wm.panes.get(&id)` and render `CompositePaneWidget::with_config(pane, false, &pane_cfg).with_palette(Some(pane_palette)).render(inner_rect, buf)`.
       - `DrawerPreviewTarget::QuickTerminal`: render `&wm.quick_terminal.pane` via `CompositePaneWidget::with_config(&wm.quick_terminal.pane, false, &wm.config.pane).render(inner_rect, buf)`.
       - `DrawerPreviewTarget::BackgroundPane { session_name, pane_id }`: look up `wm.window_manage.background_sessions.get(&session_name).and_then(|bg| bg.panes.get(&pane_id))` and render via `CompositePaneWidget::with_config(pane, false, &wm.config.pane).render(inner_rect, buf)`.
       - `DrawerPreviewTarget::SavedSession { session_name }`: render the cached `SavedWorkspaceSession` from `wm.drawer.preview.cached_session_snapshot` (header showing session name, window count, layout mode, active pane CWD, followed by the active saved pane's `scrollback_tail` lines).

   - Declare `pub mod drawer_preview;`.
   - In `WorkspaceWidget::render` immediately after `drawer::render_workspace_drawer(self.wm, ws_area, buf);`, call `drawer_preview::render_drawer_preview_overlay(self.wm, ws_area, buf);`.
