1. In `src/input/keymap_tables.rs`:
   - Add `Alt+P` in `DEFAULT_GLOBAL_BINDINGS` and `P` (`Shift+P`) in `DEFAULT_LEADER_BINDINGS` mapped to `Action::DrawerPreview(DrawerPreviewOp::Toggle)`.
2. In `src/input/modal.rs` (`ModalState::Drawer` key handler) and `src/input/drawer_navigator.rs` (`handle_navigator_drawer_key`):
   - Map `KeyCode::Char('v')` to `Action::DrawerPreview(DrawerPreviewOp::Toggle)`.
   - On `KeyCode::Esc`: if `self.drawer.preview.active` is `true`, dismiss the preview (`self.execute_drawer_preview_op(DrawerPreviewOp::Off)`) first; if already `false`, close the drawer as before.
   - On `KeyCode::Enter`: if `self.drawer.preview.active` is `true`, call `self.commit_drawer_preview()` so any previewed window (including a background session's specific child window) is brought into focus and the drawer closes.
3. In `src/input/mouse.rs` and `src/input/mouse_wm.rs` and `src/input/drawer_navigator.rs`:
   - **Preview Pane Hit-Testing (prioritized before underlying tiled/stacked panes in `handle_wm_mouse_event`)**:
     - If `let Some(p_rect) = self.drawer_preview_rect(ws_area)` and `p_rect.contains(Position::new(mouse.column, mouse.row))`:
       - `MouseEventKind::Down(MouseButton::Left)`:
         - If `crate::ui::drawer_preview::is_preview_close_click(p_rect, mouse.column, mouse.row)`: execute `DrawerPreviewOp::Off`.
         - Else: execute `DrawerPreviewOp::Commit` (focuses the previewed pane/session and closes the preview & drawer).
       - `MouseEventKind::Down(MouseButton::Right)` or `KeyCode::Esc`: execute `DrawerPreviewOp::Off`.
       - Consume `Drag`/`Up`/`Moved`/`ScrollUp`/`ScrollDown` inside `p_rect` so events never leak to occluded background panes.
   - **Drawer Mouse Wheel & Hover Preview**:
     - In `Classic` drawer (`src/input/mouse_wm.rs:867-875`), update `MouseEventKind::ScrollUp` and `MouseEventKind::ScrollDown` to move `self.drawer.selected_index` via `self.drawer_select_prev()` / `self.drawer_select_next()` (which activates and updates the live Peek Preview when `auto_preview_on_scroll` is `true`) without stealing active pane focus.
     - In `Navigator` drawer (`src/input/drawer_navigator.rs:152-158`), `ScrollUp` / `ScrollDown` over `drawer_rect` moves `selected_index` by 1 row (`DrawerNavOp::Prev` / `DrawerNavOp::Next`) and activates/updates the Peek Preview.
     - On `MouseEventKind::Moved` inside `drawer_rect`: when `self.drawer.preview.active` is `true`, hovering over a valid window/session row updates `self.drawer.selected_index` and refreshes `sync_drawer_preview_cache()` so moving the mouse down the drawer smoothly scrubs through window previews.
     - Clicking the `[👁 Peek]` badge in either drawer style dispatches `Action::DrawerPreview(DrawerPreviewOp::Toggle)`.
  </action>
