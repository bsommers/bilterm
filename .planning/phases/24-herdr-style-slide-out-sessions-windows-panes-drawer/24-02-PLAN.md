<task type="auto">
  <name>Task 1: Create `src/ui/drawer.rs` and wire into `WorkspaceWidget` and `GuiWorkspaceRenderer`</name>
  <files>src/ui/drawer.rs, src/ui/mod.rs, src/ui/renderer.rs</files>
  <action>
1. Create `src/ui/drawer.rs` implementing `pub fn render_workspace_drawer(wm: &WindowManager, workspace_area: Rect, cfg: &BiltermConfig, palette: &ThemePalette, glyphs: &GlyphSet, buf: &mut Buffer)`:
   - In `DrawerLayoutMode::Overlay`, call `render_drop_shadow_styled` (when `cfg.drop_shadows`) and `occlude_rect(buf, drawer_rect)`.
   - In `DrawerLayoutMode::Push`, call `occlude_rect(buf, drawer_rect)`.
   - Render Borland frame (`render_borland_frame_styled`) with title showing `[HERDR DRAWER]` plus interactive badges `[D:Left/Right/Top/Bottom]`, `[M:Float/Push]`, `[P:Fixed/Auto/OnDemand]`, and `[▪]`.
   - For `Left`/`Right` vertical edges: render hierarchical rows (`SessionHeader`, `LayoutGroup`, `Pane`, `QuickTerminal`, `FleetNode`) with selected-row highlight and footer hint bar (`j/k:Nav Enter:Go Spc:Peek x:Close z:Zoom d:Edge m:Mode p:Pin`).
   - For `Top`/`Bottom` horizontal edges: render compact multi-row ribbon/tabs + selected pane telemetry line.
2. Invoke `render_workspace_drawer` inside `WorkspaceWidget::render` in `src/ui/mod.rs` (ensuring `GuiWorkspaceRenderer` and `WorkspaceRecorder` automatically capture the rendered drawer).
3. Add `drawer_rect: Option<Rect>` to `WorkspaceFrameSnapshot` in `src/ui/renderer.rs`.
  </action>
  <verify>cargo check</verify>
  <done>Drawer renders in both `RatatuiWorkspaceRenderer` and `GuiWorkspaceRenderer` across all 4 edges and both layout modes.</done>

<task type="auto">
  <name>Task 2: Add `Action` variants, `:drawer` parser/executor, keyboard modal navigation, and mouse handlers</name>
  <files>src/action.rs, src/colon_command/parse.rs, src/colon_command/execute.rs, src/input/keymap.rs, src/input/modal.rs, src/input/mouse.rs, src/api/rpc.rs</files>
  <action>
1. In `src/action.rs`, add `DrawerToggle`, `DrawerFocus`, `DrawerDock(Option<DrawerEdge>)`, `DrawerVisibility(Option<DrawerVisibilityMode>)`, `DrawerLayout(Option<DrawerLayoutMode>)`, and `DrawerSize(u16)`, and register them in `every_action_is_reachable_from_keymap_colon_or_rpc`.
2. In `src/colon_command/parse.rs`, parse `:drawer` / `:sidebar` / `:panels`:
   - `:drawer` / `:drawer toggle` -> `Action::DrawerToggle`
   - `:drawer focus` / `:drawer open` -> `Action::DrawerFocus`
   - `:drawer left|right|top|bottom|edge` -> `Action::DrawerDock(...)`
   - `:drawer fixed|pin|autohide|auto|ondemand` -> `Action::DrawerVisibility(...)`
   - `:drawer float|overlay|push|bump|mode` -> `Action::DrawerLayout(...)`
   - `:drawer size <n>` / `:drawer width <n>` / `:drawer height <n>` -> `Action::DrawerSize(n)`
3. In `src/colon_command/execute.rs`, route `Action::Drawer*` to `wm.execute_drawer_action(cmd)` (defined in `src/wm/drawer.rs`).
4. In `src/input/keymap.rs`, bind `Alt+b` (global) and leader `b` / `w` to `Action::DrawerToggle` / `Action::DrawerFocus`.
5. In `src/input/modal.rs`, when `wm.drawer().focused` is true, handle `j`/`Down`, `k`/`Up`, `h`/`Left`, `l`/`Right`, `Enter` (focus & close), `Space` (preview/raise while staying in drawer), `x` (close selected pane), `z` (zoom selected pane), `d` (cycle dock edge), `m` (toggle `Overlay`/`Push`), `p` (toggle pin `Fixed`/`AutoHide`), and `Esc`/`q` (unfocus/close drawer).
6. In `src/input/mouse.rs`, add mouse handling for the drawer in `handle_wm_mouse_event`:
   - `MouseEventKind::Moved`: update `wm.update_drawer_hover(mouse.column, mouse.row, workspace_area)` so hovering near the docked edge reveals an `AutoHide` drawer.
   - `MouseEventKind::Down(MouseButton::Left)` inside `drawer_rect`: handle border drag start, header badge clicks (`[D:...]`, `[M:...]`, `[P:...]`, `[▪]`), or row click to focus/select pane.
   - `MouseEventKind::Drag(MouseButton::Left)` when `drawer.resizing_drag`: dynamically resize `width_cols` (`Left`/`Right`) or `height_rows` (`Top`/`Bottom`), calling `wm.resize_all(workspace_area)` if in `Push` mode.
  </action>
  <verify>cargo test --lib</verify>
  <done>All `Action::Drawer*` variants, `:drawer` subcommands, keyboard navigation keys, and mouse interactions pass unit tests.</done>
</task>
