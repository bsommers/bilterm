Create `src/wm/drawer.rs` (`<= 550` lines) defining:
1. `DrawerEdge` (`Left`, `Right`, `Top`, `Bottom`) with `cycle(self) -> Self`, `label(self) -> &'static str`, and `is_vertical(self) -> bool`.
2. `DrawerVisibilityMode` (`OnDemand`, `Fixed`, `AutoHide`) with `label(self) -> &'static str` and `toggle_pin(self) -> Self`.
3. `DrawerLayoutMode` (`Overlay`, `Push`) with `toggle(self) -> Self` and `label(self) -> &'static str`.
4. `DrawerConfig` (`Serialize, Deserialize, Clone, Debug, PartialEq, Eq`) with `edge: DrawerEdge`, `visibility: DrawerVisibilityMode`, `layout: DrawerLayoutMode`, `width_cols: u16` (default `32`), `height_rows: u16` (default `6`).
5. `WorkspaceDrawer` runtime state: `open: bool`, `focused: bool`, `hover_active: bool`, `selected_index: usize`, `scroll_offset: usize`, `resizing_drag: bool`, `pane_prev_bytes: BTreeMap<PaneId, usize>`, `pane_sparklines: BTreeMap<PaneId, [u8; 6]>`, `tick_counter: usize`.
6. `DrawerRowKind` (`SessionHeader`, `LayoutGroup`, `Pane(PaneId)`, `QuickTerminal`, `FleetNode(String)`) and `DrawerRow` containing `kind`, `connector` (`"├─"` / `"╰─"` / `""`), `focus_rank_badge` (`"► [1] Z:1/4"`), `spinner` (`char` from `['⠋','⠙','⠹','⠸','⠼','⠴','⠦','⠧','⠇','⠏']`), `sparkline` (`String` of 6 bars from `['▁','▂','▃','▅','▆','▇']`), `cmd_badge` (`"⚙ RUN"`, `"✓ 0"`, `"✗ N"`, or `"IDLE"`), `mode_badges: Vec<String>` (`"🖥 ALT"`, `"🔑 !ECHO"`, `"🔒 PROT"`, `"⏺ REC"`, `"📡 BCAST"`, `"🔔 N"`), `transport_badges: Vec<String>` (`"🌐 SSH"`, `"🔗 TMUX"`), `title: String`, and `formatted_line(&self) -> String`.
7. `impl WindowManager` methods in `src/wm/drawer.rs`:
   - `drawer(&self) -> &WorkspaceDrawer`, `drawer_mut(&mut self) -> &mut WorkspaceDrawer`
   - `is_drawer_effectively_visible(&self) -> bool` checking `open || focused || visibility == Fixed || (visibility == AutoHide && (leader_pending || hover_active || has_background_pane_alert()))`
   - `drawer_rect(&self, workspace_area: Rect) -> Option<Rect>`
   - `effective_workspace_area(&self, workspace_area: Rect) -> Rect` (subtracts `drawer_rect` when `is_drawer_effectively_visible() && layout == DrawerLayoutMode::Push`, returns unchanged `workspace_area` in `Overlay` mode)
   - `drawer_rows(&self) -> Vec<DrawerRow>`
   - `update_drawer_telemetry(&mut self)` (updates per-pane byte deltas and sparkline ring buffers during `poll_all_ptys`)
   - Navigation & control helpers: `toggle_drawer(&mut self)`, `focus_drawer(&mut self)`, `close_drawer(&mut self)`, `cycle_drawer_edge(&mut self)`, `toggle_drawer_layout(&mut self)`, `toggle_drawer_pin(&mut self)`, `resize_drawer(&mut self, size: u16)`, `drawer_select_next(&mut self)`, `drawer_select_prev(&mut self)`, `drawer_activate_selected(&mut self, close_after: bool)`, `drawer_close_selected_pane(&mut self)`, `drawer_zoom_selected_pane(&mut self)`.
