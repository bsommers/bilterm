1. `keyconflict_data.rs` (declarative, data only): `ReservedChord{chord:&str, os:Option<HostOs>, surface:Option<Surface>, severity:Severity, class:Class, consumer:&str, note:&str}`. Seed `RESERVED_HOST` (Block) and `RESERVED_CONSUMERS` (Warn) from 63-RESEARCH matrix A/B: macOS `Cmd+Space/Tab/H/M`, `Ctrl+Up/Left/Right`; Windows `Alt+F4`, `Alt+Tab`, `Alt+Space`(Warn), `Ctrl+Alt+Del`, AltGr-sensitive `Ctrl+Alt+<letter>` (Warn, Windows only); Linux/GNOME/KDE `Alt+F2/F4/F7/F8`, `Alt+Tab`, `Ctrl+Alt+T/L/D/F1-F7`; any `Super`/Win chord on every OS; readline (`Ctrl+A E B F P N K U W Y R S L D T H`, `Ctrl+_`, `Alt+B F D T U L C R Y`), emacs, vim, tmux, screen, zellij, herdr (`Ctrl+B`, configurable), Claude Code (`Alt+P/T/O/B/F/D/Y/V`, `Ctrl+X Ctrl+K`), Windows Terminal host chords. Each row carries a source tag comment `CITED`/`ASSUMED` mirroring 63-RESEARCH.
2. `keyconflict.rs`: `Finding{chord:String, action:Option<Action>, severity, class, consumer:String, note:String, source:&'static str /* default|keys.bind|keybindings */}`; `check(effective, env, cfg)->Vec<Finding>`: (a) internal: duplicates after Shift-folding not in `ALLOWED_SHADOWS`, user binds shadowing a shipped binding (info), router-shadowed chords (a chord whose table entry is unreachable because an earlier branch in `handle_wm_key_event` consumes it, e.g. reserved Ctrl+Alt chords); (b) host and (c) consumer lookups filtered by `env`. Also `validate_user_bindings(cfg,&env)->Result<(),BiltermError::Config>` used at load: Block => `Err("key binding 'Alt+F4' is reserved by Windows (close window)")`, Ctrl+Q shadow => Err. Output ordering deterministic (severity, chord) for snapshot stability. `explain(chord, effective, env)->String` returns action, table origin (default/profile/user), and any findings.
3. Unit tests: each class once; deterministic ordering; `shipped_profiles_have_no_block_findings` over `{mac,windows,linux,portable}` x `{Tui,Gui}` x kitty on/off; every `ALLOWED_SHADOWS` entry has a non-empty reason.
