<objective>
Introduce the platform-aware key model (`KeyEnv`, `Primary`, `KeyChord`, per-OS `KeyProfile`s), fix the compose/AltGr/normalizer defects that make `Alt+<printable>` hotkeys unusable on macOS and non-US layouts, replace `Alt+M` with harmonized bindings, and freeze the new `Action` surface (`WindowMode`, `MenuOpen`, `Keys`) so plans 63-02 and 63-03 can run in parallel (`KEY-02`, `KEY-03`).
</objective>
