  <action>

   - `scan_dec_line_size_escapes(bytes: &[u8], cursor_row: u16, attrs: &mut BTreeMap<u16, LineSizeAttr>)` parsing `ESC # 3` (`DoubleHeightTop`), `ESC # 4` (`DoubleHeightBottom`), `ESC # 5` (`Single`), and `ESC # 6` (`DoubleWidth`).
