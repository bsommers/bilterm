# `AGENTS.md` / `CLAUDE.md` rules for Bilterm automation

The rules block that used to be pasted from this page is now generated by Bilterm, so it always matches the installed version. The source is [`docs/agent-guide.md`](../agent-guide.md).

```bash
bilterm agents-md                       # print the guide
bilterm agents-md --install             # add or refresh it in ./AGENTS.md
bilterm agents-md --install CLAUDE.md   # or in another file
```

`--install` writes the guide between `<!-- BILTERM:AGENTS-MD:BEGIN ... -->` and `<!-- BILTERM:AGENTS-MD:END -->`. Text outside the markers is never changed, and running it again after an upgrade refreshes only that block. For `.cursorrules` or another format, redirect the output: `bilterm agents-md > bilterm-rules.md`.

Other ways to reach the same text:

| Surface | How |
| :--- | :--- |
| MCP | `initialize` returns short `instructions`; the resource `bilterm://agents-md` returns the full guide |
| RPC / `bilterm ctl` | `bilterm ctl agent.guide` |
| A running agent pane | `:agent guide` (`Ctrl+Alt+G`, menu Help > Inject Agent Guide) or `bilterm agent guide SELECTOR` |

If you pasted the old block into a project, delete it and run `bilterm agents-md --install`.
