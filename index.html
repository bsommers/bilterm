[■] Quick Start & One-Line Installer

$ curl -fsSL https://raw.githubusercontent.com/bsommers/bilterm/main/scripts/install.sh | bash

Linux & macOS supported (Windows via source/cargo). Installs pre-built binary to ~/.local/bin with manpage, bash/zsh/fish completions, and desktop icon.

# Build from Source (Rust 1.88+, Edition 2024):
git clone https://github.com/bsommers/bilterm.git && cd bilterm
cargo build --release && install -m 0755 target/release/bilterm ~/.local/bin/bilterm

Agent-to-Agent Messaging

Direct inter-agent communication across terminal panes: :agent send <name> <msg>, per-agent bounded mailboxes (64 max), and 3 delivery modes: mailbox, nudge (when shell is idle), and file (for large payloads).

JSON-RPC agent.* • MCP bilterm_agent_mail • Loop guard (8 hops) • Rate limiter

Unified Registry & Fuzzy Find

Instant global search across agents, active and saved sessions, and command history: :find agent|session|history <query> or Ctrl+Alt+F. Automatic zero-trust secret masking protects tokens and credentials.

Fast nucleo-matcher • Secret redaction • Read-only RPC find.* & MCP bilterm_find

Profile export/import/save • Non-destructive design tokens • Frosted glass controls

Persistent SSH + tmux Fleet

Remote tmux -CC bridge • Scrollback replay • Crash prevention banner

[■] Core Architectural Pillars

Composite Terminal Panes

The floating command prompt, scrolling PTY output canvas, and 3270 OIA status bar form a single atomic pane. Command prompt can float, pin to top/bottom, or split, with zero SIGWINCH geometry thrashing.

Auto-hides on vim / htop (DECSET 1049) • 3-signal !ECHO LOCK password protection

2D Rectangular Block Select & Copy

Hold Alt+LeftDrag or toggle :rect mode to select, highlight, and copy rectangular columns and boxes directly out of terminal output, table columns, or logs. Pastes cleanly to system and OSC 52 clipboards.

Keyboard Alt+R • Vi copy mode r/R • Coordinate-based :rect r1 c1 r2 c2

Full Session Persistence

Detach with Ctrl+X D or :detach. Bilterm serializes the complete workspace: split tree geometry, z-stack order, prompt anchors, active shells, running commands, and per-pane working directories (CWD).

Resume via bilterm attach • Atomic 0600 crash journals • Exit Guard protection

Native Desktop GUI (--gui)

Run standalone without a host terminal using hardware-accelerated desktop rendering on Linux (X11), macOS (Cocoa), and Windows (Win32 GDI). Scale each pane's font independently from 50% to 300% (Ctrl+Wheel).

All-border mouse resizing • High-res Kitty/Sixel/Braille graphics • Custom TTF/OTF fonts

Mainframe Paging & QuickSelect

Experience classic IBM 3270 mainframe paging: MORE... / HOLDING page pauses prevent run-away flood from blowing away your output buffer. QuickSelect hints (F3) jump to URLs, paths, and hashes.

Vi Copy Mode (F8) • Mainframe Cross-hairs (Alt+X) • Spotlight / Zoom Lens (Alt+O)

Zero-Trust Confinement

All IPC sockets, session TOMLs, command history exports, and .cast recordings reside in 0700 directories with 0600 atomic file permissions. Unix domain sockets enforce SO_PEERCRED UID checking.

No secrets on CLI argv • Bearer token authentication • Secret-masked history logs

[■] API, JSON-RPC & MCP Automation

Bilterm is built from the ground up for autonomous AI coding agents, robot test harnesses, and external script orchestration:

Model Context Protocol (MCP)

Run bilterm --mcp for 11+ first-class MCP tools and dynamic resources:

bilterm_agent_mail • bilterm_find • bilterm_run_action • bilterm_session_manager • bilterm://state • bilterm://config • bilterm://agent/{name}/inbox

Strict JSON-RPC 2.0 & HTTP+SSE

Drive headless workspaces via bilterm ctl or HTTP transport (--http 127.0.0.1:9090):

agent.send • agent.wait • find.agents • window.move • daemon.list • wm.command • pane.send_keys • workspace.status
# Example: Sending a message to an agent via bilterm ctl
$ bilterm ctl agent.send '{"to":"auditor","body":"Review PR #42","mode":"mailbox"}'
{"jsonrpc":"2.0","result":{"delivered":true,"msg_id":"msg-104"},"id":1}
